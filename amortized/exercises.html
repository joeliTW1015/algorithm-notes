作答格式詳解依 2026 第一次小考的給分標準撰寫：
  • 先寫結論（是 / 否、amortized cost 是多少），再寫理由；沒有理由或計算過程不給分。
  • Aggregate：算出 \(n\) 個操作的總成本 \(T(n)\)，amortized = \(T(n)/n\)。
  • Accounting：列出每種操作的 \(c_i\) 與收費 \(\hat c_i\)，說明 credit 永遠 \(\ge0\)。
  • Potential：定義 \(\Phi\)，檢查 \(\Phi(D_0)=0\)、\(\Phi(D_i)\ge0\)，再逐一算 \(\hat c_i=c_i+\Delta\Phi\)。

16.1 Aggregate analysis

16.1-1加入 MULTIPUSH，\(O(1)\) 還成立嗎？
stack 操作再加一個 MULTIPUSH(k)：一次 push k 個元素。stack 操作的 amortized cost 還是 \(O(1)\) 嗎？
詳解

不成立。

Why原本的論證是「pop 的總數 \(\le\) PUSH 的次數 \(\le n\)」；MULTIPUSH(k) 一次放入 \(k\) 個，push 的元素總數不再 \(\le n\)。

Counterexample交替做 MULTIPUSH(k)、MULTIPOP(k) 共 \(n\) 次，每次成本 \(k\)：總成本 \(nk\)。取 \(k=n\) → \(\Theta(n^2)\)，每個操作 amortized \(\Theta(n)\ne O(1)\)。∎

16.1-2加入 DECREMENT，n 個操作要 \(\Theta(nk)\)
在 k-bit counter 加入 DECREMENT 操作。證明 n 個操作的成本可以高達 \(\Theta(nk)\)。
詳解

Upper每個操作最多翻 \(k\) 個 bit → 總成本 \(O(nk)\)。

Lower從 \(0\) 開始交替做 DECREMENT、INCREMENT：
00…0 →DEC→ 11…1（翻 \(k\) 個）→INC→ 00…0（翻 \(k\) 個）→ …
每個操作都翻 \(k\) 個 → 總成本 \(nk=\Omega(nk)\)。

所以最壞是 \(\Theta(nk)\)。∎

不用 wrap-around 也可以：先 INCREMENT 到 011…1，之後交替 INC（→100…0）、DEC（→011…1），每次都翻 \(k\) 個。

互動驗證

16.1-3第 i 個操作在 i 是 2 的冪時成本 i
一串 n 個操作，第 i 個操作的成本是 i（如果 i 剛好是 2 的冪），否則是 1。用 aggregate analysis 求每個操作的 amortized cost。
詳解

Amortized cost \(\lt3=O(1)\)。

\(1..n\) 中 2 的冪有 \(2^0,\dots,2^m\)（\(m=\lfloor\lg n\rfloor\)），其餘每個成本 1： $$\sum_{i=1}^{n}c_i\le\sum_{j=0}^{m}2^j+n=(2^{m+1}-1)+n\lt2n+n=3n\qquad(2^m\le n).$$ Amortized cost \(=\sum c_i/n\lt3=O(1)\)。∎

16.2 The accounting method

16.2-1每 k 個操作備份一次的 stack
對一個大小永遠不超過 k 的 stack 做 PUSH、POP。每做完 k 個操作，就自動把整個 stack 複製一份備份。用 accounting method 指定適當的 amortized cost，證明 n 個操作（包含複製）的總成本是 \(O(n)\)。
詳解
操作actual \(c_i\)amortized \(\hat c_i\)
PUSH12
POP12
COPYstack 大小 \(\le k\)0

CreditPUSH、POP 各付自己 $1，另存 $1。兩次 COPY 之間剛好 \(k\) 個操作，存了 $\(k\)；COPY 最多複製 \(k\) 個，付得起。所以 credit 永遠 \(\ge0\)。

⇒ 總成本 \(\le\sum\hat c_i=2n=O(n)\)。∎

互動驗證

16.2-3Counter 加上 RESET，n 個操作仍是 \(O(n)\)
counter 除了 INCREMENT，還要能 RESET（所有位元歸零）。檢查或修改一個位元算 \(\Theta(1)\)。說明怎麼用位元陣列實作，讓從 0 開始的任意 n 個 INCREMENT / RESET 總共 \(O(n)\) 時間。（提示：記住最高位的 1 在哪。）
詳解

Idea多存 max = 最高位的 1 的位置（全 0 時為 −1），RESET 只清 \(A[0..\max]\)。

i = 0
while i < k and A[i] == 1
    A[i] = 0                  // 1 → 0
    i = i + 1
if i < k
    A[i] = 1                  // 0 → 1
    if i > max then max = i   // 更新最高位
else max = -1                 // 繞回 0

for i = 0 to max              // 只清到最高位
    A[i] = 0
max = -1
操作actual \(c_i\)amortized \(\hat c_i\)
INCREMENT\(t+1\)（翻 \(t\) 個 1 → 0、一個 0 → 1）3
RESET\(\max+1\)（再加 \(O(1)\)）1

CreditINCREMENT 的 $3：$1 付 0 → 1；$1 放在這個 bit 上，付它之後的 1 → 0；$1 存進 RESET 基金。

  • INCREMENT 的 1 → 0 都由 bit 上的 $1 付。
  • RESET：counter 上次歸零後要長到最高位是 \(\max\)，至少做了 \(2^{\max}\ge\max+1\) 次 INCREMENT，基金至少 $\(\max+1\)，付得起。

Credit 永遠 \(\ge0\) ⇒ 總時間 \(\le3\cdot\#\text{INC}+\#\text{RESET}\le3n=O(n)\)。∎

16.3 The potential method

16.3-1\(\Phi(D_0)\ne0\) 時換成從 0 開始的 \(\Phi'\)
假設 \(\Phi(D_i)\ge\Phi(D_0)\) 對所有 i 成立，但 \(\Phi(D_0)\ne0\)。證明存在 \(\Phi'\) 使得 \(\Phi'(D_0)=0\)、\(\Phi'(D_i)\ge0\)（\(i\ge1\)），而且用 \(\Phi'\) 算出的 amortized cost 跟用 \(\Phi\) 的一樣。
詳解

Let \(\Phi'(D)=\Phi(D)-\Phi(D_0)\). Then

  • \(\Phi'(D_0)=0\);
  • \(\Phi'(D_i)=\Phi(D_i)-\Phi(D_0)\ge0\) (given \(\Phi(D_i)\ge\Phi(D_0)\));
  • \(\hat c_i'=c_i+\Phi'(D_i)-\Phi'(D_{i-1})=c_i+\Phi(D_i)-\Phi(D_{i-1})=\hat c_i\). ∎
16.3-3Min-heap：INSERT \(O(\lg n)\)、EXTRACT-MIN \(O(1)\)
一般的 binary min-heap，INSERT 和 EXTRACT-MIN 最壞都是 \(O(\lg n)\)（n = 目前 heap 裡的個數）。給一個 potential function \(\Phi\)，讓 INSERT 的 amortized cost 是 \(O(\lg n)\)、EXTRACT-MIN 是 \(O(1)\)，並證明。注意：不知道 heap 最多會有幾個元素。
詳解

\(\Phi(D)=c\sum_{j=1}^{n}\lg j=c\lg(n!)\)，\(n\) = heap 目前的大小。

IdeaINSERT 先預付將來 EXTRACT 的 \(O(\lg n)\)；\(\Phi\) 只依目前的 \(n\)，不需要知道最大值。

設大小為 \(n\) 時兩種操作的實際成本都 \(\le c(1+\lg n)\)（INSERT 的 \(n\) 是插入後、EXTRACT-MIN 的 \(n\) 是取出前）。\(\Phi(D_0)=0\)，且 \(\lg j\ge0\) ⇒ \(\Phi\ge0\)。

  • INSERT（\(n-1\to n\)）：\(\Delta\Phi=c\lg n\)，\(\hat c\le c(1+\lg n)+c\lg n=O(\lg n)\)。
  • EXTRACT-MIN（\(n\to n-1\)）：\(\Delta\Phi=-c\lg n\)，\(\hat c\le c(1+\lg n)-c\lg n=c=O(1)\)。∎

互動驗證（實際成本 = 1 + 交換次數，c = 1；EXTRACT-MIN 的 \(\hat c\le1\)）

16.3-4Stack 一開始有 \(s_0\) 個，最後 \(s_n\) 個
做 n 個 PUSH / POP / MULTIPOP，stack 一開始有 \(s_0\) 個元素、最後有 \(s_n\) 個。總成本是多少？
詳解

總成本 \(=2\cdot\#\text{PUSH}+s_0-s_n\le2n+s_0-s_n\)。

\(\Phi\) = stack 大小，\(\Phi(D_0)=s_0\)、\(\Phi(D_n)=s_n\)。\(\hat c\)：PUSH \(=1+1=2\)，POP \(=1-1=0\)，MULTIPOP(\(k'\)) \(=k'-k'=0\)。用 telescoping（不需要 \(\Phi(D_i)\ge\Phi(D_0)\)）： $$\sum_{i=1}^{n}c_i=\sum_{i=1}^{n}\hat c_i-\Phi(D_n)+\Phi(D_0)\le2n-s_n+s_0.\ ∎$$

不能直接說 \(O(n)\)：MULTIPOP 可以 pop 掉原本的 \(s_0\) 個，讓 \(\Phi(D_i)\lt\Phi(D_0)\)，所以要多加 \(s_0\)。

互動驗證

16.3-5用兩個 stack 做 queue
用兩個普通的 stack 實作 queue，讓 ENQUEUE 和 DEQUEUE 的 amortized cost 都是 \(O(1)\)。
詳解

IdeaIN 收新元素；OUT 空了才把 IN 整個倒進 OUT（順序反轉，最舊的在 OUT 頂端）。

ENQUEUE(Q, x)
    PUSH(IN, x)
DEQUEUE(Q)
    if STACK-EMPTY(OUT)
        while not STACK-EMPTY(IN)
            PUSH(OUT, POP(IN))     // 倒過來：最舊的到 OUT 頂端
    return POP(OUT)

\(\Phi=2\cdot|IN|\)，\(\Phi(D_0)=0\)、\(\Phi\ge0\)。每個 PUSH / POP 成本 1：

操作\(c_i\)\(\Delta\Phi\)\(\hat c_i\)
ENQUEUE1+23
DEQUEUE（OUT 非空）101
DEQUEUE（倒 \(m\) 個）\(2m+1\)\(-2m\)1

兩種操作 amortized 都是 \(O(1)\)。∎

16.3-6INSERT 與 DELETE-LARGER-HALF
設計一個資料結構存整數 multiset S（可以重複），支援 INSERT(S, x) 和 DELETE-LARGER-HALF(S)（刪掉最大的 \(\lceil|S|/2\rceil\) 個）。任意 m 個操作要 \(O(m)\) 時間，而且能在 \(O(|S|)\) 時間輸出 S 的所有元素。
詳解

Idea用沒排序的陣列存 S；刪一半時用 linear-time SELECT 找門檻。輸出直接掃一次，\(O(|S|)\)。

INSERT(S, x)
    append x to S                    // O(1)
DELETE-LARGER-HALF(S)
    s = |S|;  h = ⌈s/2⌉
    y = SELECT(S, s - h + 1)         // 第 h 大，linear-time SELECT, O(s)
    T = all x in S with x < y        // 掃一次，最多 s - h 個
    append copies of y to T until |T| = s - h   // 處理重複值
    S = T                            // 總共 O(s)

設 INSERT \(\le c\)、DELETE-LARGER-HALF \(\le c\cdot s\)。令 \(\Phi=2c\cdot|S|\)，\(\Phi(D_0)=0\)、\(\Phi\ge0\)：

  • INSERT：\(\hat c\le c+2c=3c\)。
  • DELETE-LARGER-HALF：刪掉 \(h\ge s/2\) 個，\(\Delta\Phi\le-2c\cdot\frac s2=-cs\)，\(\hat c\le cs-cs=0\)。

⇒ \(m\) 個操作總時間 \(\le3cm=O(m)\)。∎

易錯：用排序找門檻是 \(O(s\lg s)\)，\(\Delta\Phi\) 抵不掉；一定要 linear-time SELECT。

互動驗證（c = 1）
