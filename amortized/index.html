Chapter 16 · Amortized Analysis I & II

偶爾很貴，平均很便宜

有些操作單次最壞要 \(O(n)\) 或 \(O(k)\)，但它不可能每次都那麼貴。Amortized analysis 看的是一整串操作在最壞情況下的總成本，再平均到每個操作上。右邊的計數器偶爾一次翻很多位元（黃色長條），但累計成本始終在 \(2n\) 之下。

16-1 用 aggregate method 直接數總成本；16-2 用 accounting（存錢）和 potential（位能）把同樣的結論「分攤」到每個操作上。每一頁都有可以一步一步執行的互動元件（鍵盤 ← → 也能操作），以及投影片所有例題和指定習題 16.1 ~ 16.3 的詳解。

Amortized vs Average-case

一個是「最壞的一串操作」的平均，一個是「隨機輸入」的平均；quicksort 為什麼不能說 amortized \(\Theta(n\log n)\)。

 16-2 p.3–15

Accounting Method

PUSH 收 $2、INCREMENT 收 $2：多的錢存在元素 / 位元上，銀行永不透支 ⇒ 總成本 \(\le\) 總收費。

 16-2 p.16–29

Potential Method

\(\hat c_i=c_i+\Phi(D_i)-\Phi(D_{i-1})\)：\(\Phi\) = 元素個數 / 1 的個數，換錯 \(\Phi\) 會怎樣。

Amortized cost 是什麼意思

說「OP1 是 amortized \(O(x)\)、OP2 是 amortized \(O(y)\)、OP3 是 amortized \(O(z)\)」，意思是：

定義（p.3）對任何一串操作，只要其中 OP1 有 \(n_1\) 個、OP2 有 \(n_2\) 個、OP3 有 \(n_3\) 個， $$\text{最壞情況總時間} = O(n_1x + n_2y + n_3z).$$
  • 沒有機率、沒有「隨機輸入」：這是對最壞的操作順序成立的保證。
  • 個別操作仍然可能很慢（SUPER-POP 一次 \(O(n)\)），只是慢的操作不可能太常出現——前面便宜的操作「存」下了它的成本。
  • 用法：把資料結構放進一個大演算法裡時，只要知道總時間，就可以每個操作都用 amortized cost 來加。

三種方法

方法怎麼做每種操作的 amortized cost要證明投影片
Aggregate直接算出 n 個操作最壞的總成本 \(T(n)\)，除以 n全部一樣：\(T(n)/n\)\(T(n)\) 的上界16-1
Accounting每種操作「收費」不同，多收的錢存成 credit 綁在物件上，付給以後的貴操作可以不一樣存款永遠 \(\ge 0\)16-2 p.3–15
Potential定義整個資料結構的位能 \(\Phi\)，\(\hat c_i=c_i+\Delta\Phi\)可以不一樣\(\Phi(D_i)\ge\Phi(D_0)\)16-2 p.16–29
$$\underbrace{\sum_{i=1}^{n}\hat c_i-\sum_{i=1}^{n}c_i\;\ge\;0}_{\text{accounting：存款不透支}}\qquad\qquad\underbrace{\sum_{i=1}^{n}\hat c_i=\sum_{i=1}^{n}c_i+\Phi(D_n)-\Phi(D_0)}_{\text{potential：telescoping}}$$

兩者其實是同一件事：accounting 的「目前存款」就是一個合法的 \(\Phi\)。

Aggregate method 的兩步（16-1）

  1. 算總成本（aggregate）：對任意 n、任意順序的 n 個操作，找出最壞總成本 \(T(n)\) 的上界。關鍵是換個角度數：不要「每個操作最壞 × n」，而是數「每個元素 / 每個位元一共被動到幾次」。
  2. 除以操作數：amortized cost \(= T(n)/n\)，每種操作都一樣。

考前檢查清單

  • 能用一句話說出 amortized cost 的定義（p.3），並說明它是最壞情況的保證，跟機率無關。
  • 能解釋 super stack 為什麼「被 pop 的總數 ≤ push 的總數」，寫出 \(O(n^2)\) → \(O(n)\) 的論證。
  • 能手動做 INCREMENT（例如 00101 → 00110 成本 2；11111 → 00000 成本 k），說出 \(b_i\) 在第 x 次 INCREMENT 翻轉 ⇔ \(2^i \mid x\)。
  • 能寫出 \(\sum_{i=0}^{k-1}\lfloor n/2^i\rfloor < n\sum_{i\ge0}2^{-i} = 2n\)。
  • 能分辨 amortized 與 average-case，並回答 p.17「為什麼不能說 amortized sorting time = \(\Theta(n\log n)\)」。
  • 習題：MULTIPUSH 破壞 \(O(1)\)、DECREMENT 讓計數器變 \(\Theta(nk)\)、2 的冪成本序列的 aggregate 分析。
  • 16-2：能說出 accounting 的 Lemma（p.4）和它的條件「每個時間點存款 \(\ge 0\)」，並解釋為什麼不能先欠後還。
  • 能回答 p.6 的三個問題：誰存錢（PUSH）、誰領錢（POP / SUPER-POP）、存款怎麼看（stack 大小）。
  • 能用歸納法證明 counter 的「存款 = 1 的個數」，包含繞回那一步；能回答 p.14「起始值 ≠ 0 哪裡錯」。
  • 能寫出 \(\hat c_i=c_i+\Phi(D_i)-\Phi(D_{i-1})\) 和 telescoping 式，說明為什麼要 \(\Phi(D_i)\ge\Phi(D_0)\) 對所有 i。
  • Super stack 的 \(\hat c\)：PUSH 1+1、POP 1−1、SUPER-POP k−k；counter：\((t_i+1)+(1-t_i)=2\)，繞回時 0。
  • 能比較三種方法（amortized cost 是否相同、存款放哪、要證明什麼）。
  • 習題：備份 stack 收 $2、RESET 要記 max、heap 用 \(\lg(n!)\)、queue 用 \(2|IN|\)、DELETE-LARGER-HALF 要 linear-time SELECT。

投影片補充說明

16-1 Aggregate

  • p.2 的箭頭指向 Aggregate Method：16-1 只講這一種，accounting 與 potential 在下一份投影片。
  • p.4 的 SUPER-POP 就是課本的 MULTIPOP(S, k)。投影片假設 k 不超過 stack 大小；課本版本在 stack 不夠時就全部 pop 完（成本 \(\min(s,k)\)），分析結果一樣。
  • p.13 的和寫成 \(\sum_{i=0\text{ to }k}\)，但 k-bit 計數器的位元只有 \(b_0,\dots,b_{k-1}\)，嚴格來說是 \(\sum_{i=0}^{k-1}\)。多加一項不影響 \(<2n\) 的上界。→
  • p.12「\(b_i\) 在第 x 次翻轉 ⇔ x 可被 \(2^i\) 整除」是從 0 開始數、還沒繞回的情況；繞回後（\(n\ge 2^k\)）仍然成立，因為計數器就是 \(x \bmod 2^k\)。
  • p.15–17 的「average-case」是對輸入分布取平均；amortized 是對一串操作取平均，但那一串可以是最壞的。→

16-2 Accounting & Potential

  • 符號：投影片的 amortized cost 寫 \(\alpha_i\)，課本寫 \(\hat c_i\)；這裡的筆記用 \(\hat c_i\)。
  • p.4 Lemma 的「enough to pay for each operation」意思是每一個時間點存款都 \(\ge 0\)，不是只看最後；否則序列在欠錢時停下來，上界就不成立。→
  • p.13 的 Proof 只處理 counter 剛好是 \(0\,1\dots1\)（\(2^k-1\)）的情況，而且「after \(2^k-1\) increment we will save another k credit」寫法容易誤解。完整的證明是對每一次 INCREMENT 歸納「每個 1 身上恰好有 $1」，繞回那一步要另外看。→
  • p.14 的問題「初始值 ≠ 0 哪裡錯」：一開始就存在的 1 身上沒有 credit，翻回 0 時沒人付。補上初始的 \(b_0\) 元即可：總成本 \(\le 2n-b_n+b_0\)。→
  • p.24 SUPER-POP 的 \(\hat c=k+(-k)\) 假設 stack 至少有 k 個；一般是 \(k'=\min(k,s)\)，\(\hat c=k'-k'=0\)，結論不變。
  • p.25、p.28 寫「amortized cost = 2」，精確地說是「每個操作 \(\le 2\)」：POP / SUPER-POP 是 0。
  • p.27 寫 \(\hat c_i=2\) for all i；繞回那一步（\(11\dots1\to00\dots0\)）沒有位元 0→1，\(c_i=k\)、\(\Delta\Phi=-k\)、\(\hat c_i=0\)。應寫成 \(\hat c_i\le 2\)（課本即如此）。→
