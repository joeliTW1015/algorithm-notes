Potential Method 位能法

不再把錢綁在個別物件上，而是用一個函數 \(\Phi\) 量整個資料結構現在「存了多少能量」。每個操作的 amortized cost = 實際成本 + 位能的變化。位能升高 = 存錢，位能降低 = 把存款拿來付。

物理的比喻（p.16–18）

  • 物體越高，重力位能越大；位能只看物體的狀態（高度），不看它怎麼到那裡的。
  • Amortized analysis 裡，potential function \(\Phi\) 把資料結構的狀態對應到一個數字：\(\Phi(D)\)。
  • 一個操作可能讓位能上升或下降；位能就像 accounting method 裡的存款，可以拿來幫忙付之後的操作。

定義（p.19–21）

符號意思
\(\Phi\)potential function（位能函數）
\(D_i\)做完第 i 個操作後的資料結構（\(D_0\) = 一開始）
\(c_i\)第 i 個操作的實際成本
\(\hat c_i\)第 i 個操作的 amortized cost（投影片寫 \(\alpha_i\)，課本寫 \(\hat c_i\)）

p.19：位能升高 d，amortized cost 要 \(\ge\) 實際成本 + d（多付的存進位能）；位能降低 d，amortized cost 只要 \(\ge\) 實際成本 − d（降下來的位能幫忙付）。合起來（p.20）： $$\hat c_i \;\ge\; c_i + \Phi(D_i) - \Phi(D_{i-1}).$$ amortized cost 越小，分析越緊，所以一般直接取等號（p.21）：

$$\hat c_i \;=\; c_i + \underbrace{\Phi(D_i) - \Phi(D_{i-1})}_{\text{potential change } \Delta\Phi_i}$$

加總起來中間的 \(\Phi\) 全部消掉（telescoping）：

$$\sum_{i=1}^{n}\hat c_i=\sum_{i=1}^{n}\bigl(c_i+\Phi(D_i)-\Phi(D_{i-1})\bigr)=\sum_{i=1}^{n}c_i+\Phi(D_n)-\Phi(D_0).$$

什麼樣的 \(\Phi\) 可以用（p.22）

條件只要 \(\Phi(D_i)\ge\Phi(D_0)\) 對所有 i 成立，就有 $$\sum_{j=1}^{i}\hat c_j=\sum_{j=1}^{i}c_j+\underbrace{\Phi(D_i)-\Phi(D_0)}_{\ge 0}\;\ge\;\sum_{j=1}^{i}c_j\qquad\text{（任何時間點）}.$$ 最常見的寫法：取 \(\Phi(D_0)=0\)，再證明 \(\Phi(D_i)\ge 0\)。
  • 為什麼要「所有 i」：我們不知道操作序列什麼時候停，所以每個前綴都要蓋得住——跟 accounting 的「每個時間點都不透支」是同一件事。
  • 合法不代表好用：\(\Phi=0\) 永遠合法，但那樣 \(\hat c_i=c_i\)，什麼都沒分析到。目標是找讓 amortized cost 最小的 \(\Phi\)。
  • 跟 accounting 的關係：\(\Phi(D_i)\) 就是「做完第 i 個操作後銀行裡的錢」。差別在於 \(\Phi\) 只看整個資料結構的狀態，不用說明每塊錢放在哪個物件上。

結論（p.25）\(\Phi(D_i)\ge\Phi(D_0)\) ⇒ 總 amortized ≥ 總實際。每個操作的 amortized cost \(\le 2 = O(1)\)。

Binary Counter（Take 3，p.26–28）

定義 \(\Phi(B)\) = counter B 裡 1 的個數。從 0 開始：\(\Phi(D_0)=0\le\Phi(D_i)\)。

假設第 i 次 INCREMENT 把 \(t_i\) 個位元從 1 變 0（p.27）：

  1. 一般情況（有一個 0→1）：\(c_i=t_i+1\)，1 的個數少 \(t_i\) 多 1：\(\Delta\Phi=1-t_i\)。 $$\hat c_i=(t_i+1)+(1-t_i)=2.$$
  2. 繞回（\(11\dots1\to00\dots0\)，沒有 0→1）：\(c_i=t_i=k\)，\(\Delta\Phi=-k\)，\(\hat c_i=0\)。
  3. 兩種情況都有 \(\hat c_i\le 2\)。
p.27投影片寫「\(\hat c_i = 2\) for all i」，嚴格來說是 \(\le 2\)：繞回那一步 \(\hat c_i=0\)。課本寫的就是 \(\le\)。下面選「k = 4, n = 20」，第 16 步就是繞回。
結論（p.28）INCREMENT 的 amortized cost \(\le 2=O(1)\)，n 次的總實際成本 \(\le 2n\)。

起始值不是 0（回答 p.14 的問題）

Potential method 處理這個特別乾淨。設一開始有 \(b_0\) 個 1、最後有 \(b_n\) 個 1。把 telescoping 式反過來寫：

$$\sum_{i=1}^{n}c_i=\sum_{i=1}^{n}\hat c_i-\Phi(D_n)+\Phi(D_0)\;\le\;2n-b_n+b_0\;\le\;2n+k.$$
  • 這裡不需要 \(\Phi(D_i)\ge\Phi(D_0)\)：我們用的是 n 步之後的等式，直接把 \(\Phi(D_0)=b_0\) 算進去。
  • 只要 \(n=\Omega(k)\)（INCREMENT 至少跟位元數一樣多次），總成本仍是 \(O(n)\)，不管初始值是多少。
  • 在上面元件選「從 11 = 01011 開始」：看最下面的 telescoping 那一行。

解題步驟

  1. 找 \(\Phi\)：量「累積了多少之後要清掉的工作」——stack 裡的元素（之後會被 pop）、counter 裡的 1（之後會被翻回 0）。貴的操作應該讓 \(\Phi\) 掉很多。
  2. 檢查合法：\(\Phi(D_0)=0\)、\(\Phi(D_i)\ge 0\)。
  3. 每種操作算 \(\hat c=c+\Delta\Phi\)：貴的操作 \(c\) 大但 \(\Delta\Phi\) 很負，抵掉。
  4. 收尾：\(\sum c_i\le\sum\hat c_i\)。如果 \(\Phi(D_0)\ne0\)，用 \(\sum c_i=\sum\hat c_i-\Phi(D_n)+\Phi(D_0)\)。
