Activity Selection 活動選擇

新生週有一堆迎新活動，每個活動都要從頭待到尾，時間重疊的不能同時參加。怎麼選才能參加最多個？四種直覺的貪婪規則裡只有一種是對的。

問題

  • 有 \(n\) 個活動 \(A_1,\dots,A_n\)，活動 \(A_k\) 有開始時間 \(s_k\) 和結束時間 \(f_k\)，佔用半開區間 \([s_k, f_k)\)。
  • 參加 \(A_k\) 就必須在 \(s_k\) 到、待到 \(f_k\)。兩個活動相容（compatible）若區間不重疊：\(s_i\ge f_j\) 或 \(s_j\ge f_i\)。
  • 目標：選出最多個兩兩相容的活動。

該先選哪一個？

投影片列出幾種直覺：(1) 最短的、(2) 最早開始的、(3) 最早結束的、(4) 最晚開始的 / 最晚結束的。下面可以切換規則和輸入，看哪些會失敗：

最短時間：不一定最佳（p.11）

\(A_1=[4{:}50, 5{:}10)\)、\(A_2=[3{:}00, 5{:}00)\)、\(A_3=[5{:}05, 7{:}00)\)。最短的是 \(A_1\)（20 分鐘），選了它就和另外兩個都衝突，只能參加 1 個；最佳是 \(\{A_2, A_3\}\)，2 個。

不過它至少有最佳解的一半：設 \(R\) = 最短優先的結果、\(O\) = 最佳解。

  1. \(R\) 的每個活動最多和 \(O\) 的 2 個活動衝突。如果 \(r\in R\) 和 \(O\) 的 3 個以上活動衝突，因為 \(O\) 的活動彼此不重疊，中間那個 \(o\) 一定被 \(r\) 完全包住，所以比 \(r\) 短。選 \(r\) 的當下 \(o\) 還沒被刪掉（之前選的活動和 \(r\) 不衝突，也就和被 \(r\) 包住的 \(o\) 不衝突），那應該先選 \(o\)，矛盾。
  2. \(O\) 的每個活動至少和 \(R\) 的 1 個活動衝突（或就在 \(R\) 裡）。否則它和 \(R\) 全部相容，演算法結束前一定會把它選進來。
  3. 所以 \(|O|\le 2|R|\)。若 \(|O|>2|R|\)，就有某個 \(O\) 的活動沒有和任何 \(R\) 的活動衝突，\(R\) 還可以再多選一個。∎

最早開始：可能爛到只剩 1 個（p.12）

\(A_1=[3{:}00, 10{:}00)\)，\(A_2=[3{:}10, 3{:}20)\)、\(A_3=[3{:}20, 3{:}30)\)、\(A_4=[3{:}30, 3{:}40)\)……。最早開始的是又長又早的 \(A_1\)，選了就只剩它一個；最佳解是後面 \(n-1\) 個短活動全選。最壞情況：1 個 vs \(n-1\) 個，比例可以任意差。

「最少衝突」也會失敗，反例見 15.1-3（上面元件的第 4 組輸入）。

最早結束：Greedy-choice property

Lemma 1對活動選擇問題，存在一個最佳解包含「最早結束的活動」。

證明（cut-and-paste）

  1. 令 OPT 為任一最佳解，\(A_j\) 為所有活動中最早結束的。
  2. 若 OPT 包含 \(A_j\)，得證。
  3. 否則令 \(A'\) 為 OPT 中最早結束的活動。OPT 的其他活動都在 \(A'\) 結束之後才開始（它們和 \(A'\) 相容、又比 \(A'\) 晚結束）。
  4. 因為 \(f_j\le f_{A'}\)，把 \(A'\) 換成 \(A_j\) 不會和 OPT 的其他活動衝突：\(\text{OPT}-\{A'\}\cup\{A_j\}\) 仍然合法，而且個數和 OPT 一樣 ⇒ 也是最佳解，且包含 \(A_j\)。∎

Optimal substructure

Lemma 2令 \(A_j\) 為最早結束的活動，\(S\) 為和 \(A_j\) 不衝突的活動集合，OPT 為包含 \(A_j\) 的最佳解。則 \(\text{OPT}-\{A_j\}\) 是輸入為 \(S\) 的子問題的最佳解。

證明（反證）

  1. \(\text{OPT}-\{A_j\}\) 裡的活動都和 \(A_j\) 相容，所以都在 \(S\) 裡，是子問題的一個可行解。
  2. 假設它不是最佳，令 \(C\) 是 \(S\) 的最佳解，則 \(|C|>|\text{OPT}-\{A_j\}|\)。
  3. \(C\) 的活動都和 \(A_j\) 相容，所以 \(C\cup\{A_j\}\) 合法，而且 \(|C\cup\{A_j\}|>|\text{OPT}|\)，和 OPT 是最佳解矛盾。∎

貪婪演算法

兩個 lemma 合起來：選最早結束的活動 → 刪掉和它衝突的 → 對剩下的重複。

S = 所有活動
while S 不是空的
    A = S 中最早結束的活動
    選 A，並從 S 刪掉和 A 衝突的活動

n = s.length       // 已依 f 排序
A = {a1}
k = 1              // 最後選的活動
for m = 2 to n
    if s[m] >= f[k]
        A = A ∪ {am}
        k = m
return A
  • 排序後「剩下的活動中最早結束的、且不衝突的」就是往後掃遇到的第一個 \(s_m\ge f_k\) 的活動，所以只需要比較 \(s_m\) 和最後選的那個的 \(f_k\)。
  • 輸入已依結束時間排序：\(\Theta(n)\)；沒排序要先排序：\(O(n\log n)\)。

例題（p.18）：逐步執行

\(i\)123456789
\(s_i\)12415891113
\(f_i\)3578910111416

結果 \(\{a_1, a_3, a_6, a_8\}\)，4 個。最佳解不唯一：\(\{a_2, a_5, a_7, a_9\}\) 也是 4 個（它是「最晚開始」貪婪的結果，見 15.1-2）。
