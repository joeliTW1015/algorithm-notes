15.1 Activity selection

15.1-2改選「最晚開始」的活動也對
不選最早結束的，改成每次選「和已選活動相容、而且開始時間最晚」的活動。說明這也是貪婪演算法，並證明它得到最佳解。
詳解

是 greedy：每步只選目前開始最晚的活動、不回頭，剩下子問題「在 \(s_m\) 前結束的活動」。它是最佳的。

Greedy choiceLet \(a_m\) = 開始最晚的活動，\(A\) = 任一最佳解，\(a_j\) = \(A\) 中開始最晚的。若 \(a_j\ne a_m\)，令 \(A'=A-\{a_j\}\cup\{a_m\}\)。 \(A\) 中其他活動都滿足 \(f\le s_j\le s_m\)，所以 \(A'\) 相容且 \(|A'|=|A|\) ⇒ 存在包含 \(a_m\) 的最佳解。

Optimal substructure選 \(a_m\) 後剩下 \(S'=\{a: f_a\le s_m\}\)。若 \(A'-\{a_m\}\) 不是 \(S'\) 的最佳解，換成更大的會讓 \(A'\) 變大，矛盾。由歸納法，greedy 得最佳解。∎

另一個寫法：時間軸反轉 \([s,f)\mapsto[-f,-s)\)，「最晚開始」就變成「最早結束」。

15.1-3三種錯的貪婪：最短、最少衝突、最早開始
舉例說明以下三種貪婪都不一定最佳：(1) 選時間最短的；(2) 選和其他剩下活動重疊最少的；(3) 選最早開始的。
詳解

三種都不一定最佳，反例如下。

規則活動GreedyOptimal
(1) 最短\([0,5),[4,6),[5,10)\)選 \([4,6)\)，與另兩個都衝突 → 1\([0,5),[5,10)\) → 2
(2) 最少衝突見下34
(3) 最早開始\([0,10),[1,2),[2,3),[3,4)\)選 \([0,10)\) → 1其餘三個 → 3

(2)上排 \([0,3),[4,7),[8,11),[12,15)\)；中排 \([2,5),[6,9),[10,13)\)，其中 \([2,5)\)、\([10,13)\) 各再多 3 個複本。

  • 衝突數：\([6,9)\) 只有 2（\([4,7),[8,11)\)），其餘都 \(\ge4\) → greedy 先選 \([6,9)\)。
  • 上排中間兩個被刪，左右兩群各只能再選 1 個 → 共 3 個；最佳是上排 4 個。∎

15.1-5活動有價值：最大化總價值
每個活動 \(a_i\) 除了 \(s_i, f_i\) 還有價值 \(v_i\)，目標改成選出相容活動使 \(\sum v_i\) 最大。給一個多項式時間演算法。
詳解

Greedy 不行（最早結束的可能價值很低），用 DP，\(O(n\lg n)\)。

Idea依 \(f\) 排序，\(p(j)\) = 最大的 \(i<j\) 使 \(f_i\le s_j\)（沒有則 0）。\(V[j]\) = 只用 \(a_1..a_j\) 的最大價值，看 \(a_j\) 選或不選： $$V[0]=0,\qquad V[j]=\max\bigl(V[j-1],\ v_j+V[p(j)]\bigr).$$

sort activities by finish time            // f[1] ≤ … ≤ f[n]
for j = 1 to n
    p[j] = largest i < j with f[i] ≤ s[j], or 0   // binary search
V[0] = 0
for j = 1 to n
    V[j] = max(V[j - 1], v[j] + V[p[j]])  // 不選 a_j / 選 a_j
return V[n]       // 從 n 往回：v[j] + V[p[j]] ≥ V[j-1] 就選 a_j 並跳到 p[j]

Time排序 \(O(n\lg n)\) + \(n\) 次二分搜尋 \(O(n\lg n)\) + 填表 \(O(n)\) = \(O(n\lg n)\)。

15.2 Elements of the greedy strategy

15.2-20-1 knapsack 的 \(O(nW)\) DP
給一個 \(O(nW)\) 的動態規劃解 0-1 knapsack，\(n\) 是物品數、\(W\) 是背包容量。
詳解

Idea\(K[i,x]\) = 只用物品 \(1..i\)、容量 \(x\) 的最大價值，看物品 \(i\) 拿或不拿： $$K[0,x]=0,\qquad K[i,x]=\begin{cases}K[i-1,x] & w_i>x\\ \max\bigl(K[i-1,x],\ v_i+K[i-1,x-w_i]\bigr) & w_i\le x\end{cases}$$

let K[0:n, 0:W] be a new table
for x = 0 to W
    K[0, x] = 0
for i = 1 to n
    for x = 0 to W
        K[i, x] = K[i - 1, x]                    // 不拿 i
        if w[i] ≤ x and v[i] + K[i - 1, x - w[i]] > K[i, x]
            K[i, x] = v[i] + K[i - 1, x - w[i]]  // 拿 i
return K[n, W]

Time\((n+1)(W+1)\) 格，每格 \(O(1)\) → \(O(nW)\)。回溯：\(K[i,x]\ne K[i-1,x]\) 表示拿了 \(i\)，\(x\) 減 \(w_i\)。

互動驗證

15.2-3越輕越值錢的 0-1 knapsack
0-1 knapsack 中，若物品依重量遞增排序的順序，恰好也是依價值遞減排序的順序。給一個有效率的演算法並證明正確。
詳解

依重量由輕到重拿，放不下就停。\(O(n\lg n)\)（已排序則 \(O(n)\)）。

sort items so that w[1] ≤ … ≤ w[n]   // 此時 v[1] ≥ … ≥ v[n]
k = 0;  load = 0
while k < n and load + w[k + 1] ≤ W
    k = k + 1
    load = load + w[k]                // 拿第 k 個
return {1, …, k}                      // 後面更重，都放不下

Proof任取可行解 \(S=\{s_1\lt\dots\lt s_m\}\)。因 \(s_i\ge i\)：\(w_i\le w_{s_i}\)、\(v_i\ge v_{s_i}\)。

  • \(\sum_{i\le m}w_i\le\sum w_{s_i}\le W\) ⇒ \(\{1..m\}\) 也放得下 ⇒ \(m\le k\)。
  • \(\text{value}(S)=\sum v_{s_i}\le\sum_{i\le m}v_i\le\sum_{i\le k}v_i\) ⇒ greedy 最佳。∎
15.2-5用最少的單位長度區間蓋住所有點
給實數線上的點 \(\{x_1,\dots,x_n\}\)，找最少個長度為 1 的閉區間蓋住所有點，並證明正確。
詳解

排序後，每次以最左邊未覆蓋的點 \(x\) 為左端放 \([x,x+1]\)。\(O(n\lg n)\)。

sort x                         // x[1] ≤ … ≤ x[n]
S = ∅;  i = 1
while i ≤ n
    l = x[i]                   // 最左的未覆蓋點
    S = S ∪ {[l, l + 1]}
    while i ≤ n and x[i] ≤ l + 1
        i = i + 1              // 跳過被蓋到的點
return S

Time排序 \(O(n\lg n)\)；\(i\) 只增不減，掃描 \(O(n)\)。總共 \(O(n\lg n)\)。

Greedy choice某最佳解中蓋住 \(x_1\) 的區間 \([a,a+1]\) 滿足 \(a\le x_1\)，它蓋到的點都在 \([x_1,a+1]\subseteq[x_1,x_1+1]\)。換成 \([x_1,x_1+1]\) 蓋到的只多不少，仍最佳。

Optimal substructure刪掉 \([x_1,x_1+1]\) 蓋到的點後，剩下的點必須用最少區間蓋住，否則換掉會讓整體更少，矛盾。∎

互動驗證

15.2-6\(O(n)\) 解 fractional knapsack
說明如何在 \(O(n)\) 時間解 fractional knapsack。
詳解

不排序，用 linear-time SELECT 找密度 \(d_i=v_i/w_i\) 的中位數，每次丟掉一半：\(T(n)=T(n/2)+\Theta(n)=\Theta(n)\)。

if I == ∅ or W == 0
    return 0
m = median density of I                  // SELECT, O(n)
G = {i : d_i > m};  E = {i : d_i = m};  L = {i : d_i < m}   // O(n)
if w(G) ≥ W
    return FRAC-KNAP(G, W)               // 只會拿 G 裡的東西
if w(G) + w(E) ≥ W
    return v(G) + m · (W - w(G))         // G 全拿，E 拿一部分
return v(G) + v(E) + FRAC-KNAP(L, W - w(G) - w(E))   // G、E 全拿

Correct最佳解一定先拿密度高的；\(m\) 把物品分成「全拿 / 部分 / 不拿」三段，每次確定其中一邊。

Time\(|G|,|L|\le n/2\)，每層 \(\Theta(n)\)：\(T(n)\le T(n/2)+cn\le2cn=O(n)\)。

15.3 Huffman codes

15.3-2不是 full binary tree 就不是最佳 prefix code
證明非 full 的二元樹不可能對應最佳的 prefix code。
詳解

ProofSuppose \(T\) is not full ⇒ 有內部節點 \(u\) 只有一個小孩 \(v\)。刪掉 \(u\)，讓 \(v\) 的子樹 \(T_v\) 接到 \(u\) 的位置，得到 \(T'\)。

  • 字元仍都在葉子上 ⇒ \(T'\) 仍是 prefix code。
  • \(T_v\) 中每片葉子深度 \(-1\)，其他不變：\(B(T')=B(T)-\sum_{c\in T_v}f_c\lt B(T)\)（\(f_c>0\)）。

所以 \(T\) 不是最佳。∎

15.3-4\(B(T)\) = 所有內部節點的頻率和
證明 full binary tree \(T\) 的成本 \(B(T)\) 等於所有內部節點「兩個小孩頻率和」的總和。
詳解

Proof令內部節點 \(u\) 的頻率 \(f_u\) = 兩個小孩頻率和 = \(u\) 底下所有葉子的頻率和。葉子 \(c\) 的深度 \(d_T(c)\) = 它的內部祖先個數，所以 $$B(T)=\sum_{c}f_c\,d_T(c)=\sum_{c}\ \sum_{u\text{ ancestor of }c}f_c=\sum_{u\text{ internal}}\ \sum_{c\text{ under }u}f_c=\sum_{u\text{ internal}}f_u.\ ∎$$

例：CLRS 的 Huffman 樹，\(14+25+30+55+100=224=B(T)\)。

15.3-5用 \(2n-1+n\lceil\lg n\rceil\) bits 傳送編碼本身
有一個 \(n\) 個字元的最佳 prefix code，想用最少 bits 把「編碼表」傳出去。說明如何只用 \(2n-1+n\lceil\lg n\rceil\) bits 表示。（提示：用 \(2n-1\) bits 描述樹的形狀。）
詳解
  1. 形狀 \(2n-1\) bits：最佳樹是 full（15.3-2），有 \(n\) 片葉子、\(n-1\) 個內部節點。Preorder 走訪，內部節點寫 1、葉子寫 0。Full tree 看到 1 就知道後面接左右兩棵子樹，可唯一重建。
  2. 葉子 \(n\lceil\lg n\rceil\) bits：依同樣的 preorder 順序寫出每片葉子的字元編號，每個 \(\lceil\lg n\rceil\) bits。
  3. 合計 \(2n-1+n\lceil\lg n\rceil\) bits。∎

例：CLRS 的 Huffman 樹，形狀 10110011000（11 bits），葉子 a c b f e d 各 3 bits，共 29 bits。

Problems

15-1Coin changing
用最少枚硬幣找 \(n\) 分錢。(a) 面額 25、10、5、1 時設計貪婪並證明最佳。(b) 面額是 \(c^0,c^1,\dots,c^k\)（\(c>1, k\ge1\)）時證明貪婪最佳。(c) 給一組（含 1）讓貪婪失敗的面額。(d) 給 \(O(nk)\) 的演算法處理任意 \(k\) 種面額（含 1）。
詳解

(a)Greedy：依序拿最多的 25、10、5、1（\(q=\lfloor n/25\rfloor\)，對餘數重複）。
Proof：最佳解中 1 分 \(\le4\) 枚（5 枚可換一枚 5）、5 分 \(\le1\)（2 枚換 10）、10 分 \(\le2\)（3 枚換 25+5），且不會同時有 2 枚 10 和 1 枚 5（換 25）。 所以小於 25 的硬幣總額 \(\le 20+4=24\lt25\) ⇒ 25 分的枚數必為 \(\lfloor n/25\rfloor\)；同理小於 10 的總額 \(\le9\lt10\)、小於 5 的 \(\le4\lt5\)，每種枚數都和 greedy 相同。∎

(b)最佳解中每種 \(c^i\ (i\lt k)\) 最多 \(c-1\) 枚（\(c\) 枚可換一枚 \(c^{i+1}\)，更少）。所以比 \(c^j\) 小的硬幣總額 $$\le\sum_{i=0}^{j-1}(c-1)c^i=c^j-1\lt c^j,$$ 由 \(j=k\) 往下，每種面額的枚數都必須等於 greedy 的 \(\lfloor\text{餘額}/c^j\rfloor\)。∎

(c)\(\{1,3,4\}\)，\(n=6\)：greedy \(4+1+1\)（3 枚），最佳 \(3+3\)（2 枚）。

(d)DP：\(C[0]=0,\ C[j]=1+\min_{d_i\le j}C[j-d_i]\)（列舉最後一枚）。

C[0] = 0
for j = 1 to n
    C[j] = ∞
    for i = 1 to k
        if d[i] ≤ j and C[j - d[i]] + 1 < C[j]
            C[j] = C[j - d[i]] + 1
            coin[j] = d[i]           // 記錄最後一枚
return C[n]       // 從 j = n 起印 coin[j]，j = j - coin[j]

Time\(n\) 個子問題 × \(k\) 種面額 → \(O(nk)\)；有 1 分所以每個 \(C[j]\) 都有解。

p.44用貪婪法解 maximum-subarray
之前用 divide-and-conquer 解過 maximum-subarray（\(O(n\log n)\)）。寫出貪婪演算法的虛擬碼並分析時間。
詳解

Idea由左往右累加 \(cur\)；累加和 \(<0\) 時接在後面只會變小，直接丟掉、從下一個重新開始（Kadane）。

best = -∞;  cur = 0;  start = 1
for i = 1 to n
    if cur < 0                // 前面的和是負的：丟掉
        cur = 0;  start = i
    cur = cur + A[i]          // cur = 以 A[i] 結尾的最大和
    if cur > best
        best = cur;  (lo, hi) = (start, i)
return (lo, hi, best)

CorrectLoop invariant：第 \(i\) 圈後 \(cur=\max(A[i],\ cur_{i-1}+A[i])\) = 以 \(A[i]\) 結尾的最大子陣列和；答案是所有 \(cur\) 的最大值 = \(best\)。

Time單一迴圈 \(n\) 圈，每圈 \(O(1)\) → \(\Theta(n)\)。
