常考概念速記

DP 兩要素Optimal substructure：最佳解含子問題最佳解。Overlapping subproblems：同一子問題被重複解，相異子問題只有 polynomial 個。反例：longest simple path（子路徑共用頂點，不 independent）。→
Greedy 兩性質Greedy-choice property：存在含 greedy 選擇的最佳解（exchange argument 證）。Optimal substructure：選完只剩一個子問題，其最佳解 + greedy choice = 最佳解。→
概念考試要寫出的一句話 / 式子題目
DP 設計流程定義子問題（常用「以 i 結尾」）→ 遞迴式 + base case → bottom-up pseudocode → 逐層算 time / spaceLIS、一維 DP
填表題兩張表都寫（m / s、c / 箭頭、e / root）+ 每格計算過程 + 最後答案（括號、樹、LCS）MCM ×4、OBST
Pseudo-polynomial\(O(nW)\) 對輸入長度 \(n\lg W\) 是指數 → 不是 polynomial3 次是非題
Exchange argument最佳解 O 不含 g → 換出某 x、換入 g → 仍合法且不變差找零、intervals、Huffman
Huffmanmin-heap，n − 1 次合併，\(O(n\lg n)\)；cost = Σ f·depth = 內部節點頻率和5 次
Amortized 定義對所有序列 \(\sum\hat c_i\ge\sum c_i\)；單次可以很貴填空 / 是非
Potential method\(\hat c_i=c_i+\Phi(D_i)-\Phi(D_{i-1})\)；要 \(\Phi(D_i)\ge\Phi(D_0)\)；Φ(D₀) ≠ 0 時把差帶著2 的冪、S₀
Dynamic table\(\Phi=2\,\text{num}-\text{size}\ (\alpha\ge\frac12)\)、\(\text{size}/2-\text{num}\ (\alpha<\frac12)\)；INSERT ≤ 3、DELETE ≤ 24 次

考前檢查清單

  • 能在 10 分鐘內手算 5 個矩陣的 m、s 表並印出括號（練 2022、2023 兩組）。
  • 能默寫 MATRIX-CHAIN-ORDER、LCS-LENGTH、OPTIMAL-BST、BOTTOM-UP-CUT-ROD、HUFFMAN 的 pseudocode。
  • DP 兩要素 + longest simple path 反例：能畫出 q, r, s, t 的圖並解釋「子問題不 independent」。
  • LIS / 壽司 / max subarray：都是「以 i 結尾」的 DP；能寫出遞迴式、pseudocode、\(\sum(i-1)=O(n^2)\)。
  • 樓梯、鋪磚、不相鄰最大和：會用「最後一步」分類，base case 寫對（\(F_0=1\)、\(f(0)=1\)）。
  • 能說出 0/1 knapsack 的 \(O(nW)\) 為什麼不是 polynomial。
  • 找零錢：能寫出美金 Lemma（penny ≤ 4、nickel ≤ 1、dime ≤ 2、不同時 2D + 1N）和 c 次方的等比級數證明。
  • Huffman：能建樹、寫碼、算 cost，證明「最小兩個可以是最深兄弟」和「頻率遞減 ⇒ 碼長遞增」。
  • Greedy 證明一律寫兩段：greedy-choice（exchange）+ optimal substructure（cut-and-paste）。
  • \(c_i=i\)（2 的冪）：aggregate \(<3n\)、accounting 收 $3、potential \(\Phi=2(i-2^{\lfloor\lg i\rfloor})\)；知道 \(\Phi=i-2^{\lfloor\lg i\rfloor}\) 為什麼不夠。
  • Dynamic table：會 8 種情況的 \(\hat c\)，能在 5 分鐘內填完 12 步的 num / size / c / Φ / α 表（剛好 1/4 不縮）。
  • Stack / counter 變形：Φ(D₀) ≠ 0 要帶著 \(\Phi(D_0)-\Phi(D_n)\)；CUT 每個物件存 $2；RESET 要記 max。

補充說明

答案鍵的錯誤

  • 2020 Q3（鋪磚）：dp[0] = 0 會讓 k = 2、n = 3 算出 2，應為 3；base case 要 \(f(0)=1\)。→
  • 2018 Q6（找零 DP）：內圈迴圈變數寫成 i、比較少了 +1。→
  • 2018 Q7（unit intervals）：「x′ < 1」應為 x′ ≤ y₁。→
  • 2018 Q8（Huffman 碼長）：符號與結論寫反，正確是「交換後成本不增加」，不是推出矛盾。→
  • 2013 Q10：兩個性質的說明文字貼成同一段；2022 Q1 的 n-queen 例子不是最佳化問題，建議寫 longest simple path。→

檔名與內容對不上

  • 09910_…_mid.pdf 其實是兩份考卷：p.1–2 是 2010/10/26 第一次考（全部範圍外），p.3–4 是 2011/12/16 第二次考（範圍內 7 題）。
  • 11210_…_mid_ans.pdf 不是 2023/11/10 期中考（11210_…_mid.pdf）的答案，題目完全不同；它涵蓋 greedy、amortized、圖論、NP，檔案建立於 2024/01，推測是之後的另一次考試。這裡標為「2024」。
