Amortized 考古題

Amortized 題型很集中：觀念填空、ci = i（i 是 2 的冪）、dynamic table 的 Φ、stack / counter 的變形。常要求「用指定的方法」（aggregate / accounting / potential）——照指定方法寫才給分。

三種方法的答題模板
方法要寫的東西
Aggregate對任意 n 個操作算總成本上界 \(T(n)\)（換個角度數），amortized = \(T(n)/n\)。
Accounting列出每種操作的收費 \(\hat c\)；說明多收的錢存在哪個物件上、付哪個未來操作；證明任何時刻存款 ≥ 0 ⇒ \(\sum c_i\le\sum\hat c_i\)。
Potential定義 \(\Phi\)，證 \(\Phi(D_0)=0\)、\(\Phi(D_i)\ge0\)；每種操作算 \(\hat c_i=c_i+\Phi(D_i)-\Phi(D_{i-1})\)；\(\sum c_i=\sum\hat c_i-\Phi(D_n)+\Phi(D_0)\le\sum\hat c_i\)。

觀念：amortized vs actual

2017 Q1b · 2018 Q1seefoo：amortized 與單次最壞6%

If a data structure supports an operation seefoo such that a sequence of n seefoo's operations takes Θ(n log n) time to perform in the worst case, then the amortized cost of a seefoo operation is Θ(__(1)__), while the actual time of a seefoo operation could be as high as Θ(__(2)__).

若某資料結構的操作 seefoo，做 n 次最壞要 \(\Theta(n\log n)\)，則 seefoo 的 amortized cost 是 Θ(__(1)__)，而單一次 seefoo 的實際時間最高可達 Θ(__(2)__)。

詳解

(1) \(\Theta(\log n)\)　(2) \(\Theta(n\log n)\)

Whyamortized = 總成本 / 操作數 = \(\Theta(n\log n)/n\)。單次沒有限制：可能前 n − 1 次都 O(1)，最後一次把 \(\Theta(n\log n)\) 全做完。

2017 Q2bTrue / False：總 amortized cost 是總 actual cost 的上界2%

For each of the following statements, determine whether it is true or false. If the statement is correct, briefly state why. If the statement is wrong, explain why. (b) The total amortized cost of a sequence of operations gives an upper bound on the actual cost of the sequence.

是非題（看解釋給分）：一串操作的總 amortized cost 是這串操作實際總成本的上界。

詳解

True。

Why定義 amortized cost 時就要求對所有序列 \(\sum_{i=1}^{n}\hat c_i\ge\sum_{i=1}^{n}c_i\)：accounting 是存款永不為負；potential 是 \(\sum\hat c_i=\sum c_i+\Phi(D_n)-\Phi(D_0)\) 且 \(\Phi(D_n)\ge\Phi(D_0)\)。

注意是「總和」的上界；單一操作的 \(\hat c_i\) 可以比 \(c_i\) 小（例如 SUPER-POP 的 \(\hat c=0\)）。

Suppose we perform a sequence of n operations on a data structure in which the ith operation costs i if i is an exact power of 2, and 1 otherwise.
(a) Use the aggregate method to determine the amortized cost per operation.
(b) Use the accounting method to determine the amortized cost per operation.
(c) Use the potential method to determine the amortized cost per operation.

對資料結構做 n 個操作，第 i 個操作成本是 i（若 i 剛好是 2 的冪），否則是 1。分別用 (a) aggregate (b) accounting (c) potential method 求每個操作的 amortized cost。

2024 Q2（10%）只問 aggregate，要寫 Big-Oh。

詳解

三種方法都得到 amortized \(O(1)\)（每個操作 ≤ 3），總成本 \(<3n=O(n)\)。

(a) Aggregate $$\sum_{i=1}^{n}c_i\ \le\ \underbrace{n}_{\text{非 2 的冪，各 1}}+\underbrace{\sum_{j=0}^{\lfloor\lg n\rfloor}2^j}_{\text{2 的冪}}= n+(2^{\lfloor\lg n\rfloor+1}-1)\le n+2n-1<3n.$$ 所以 amortized cost \(=3n/n=O(1)\)。

(b) Accounting每個操作收 $3。非 2 的冪：花 $1、存 $2。由 (a)，任何前 i 個操作的實際總成本 \(<3i\) = 已收的錢，所以存款 \(3i-\sum_{t\le i}c_t>0\) 永不為負 ⇒ 總成本 ≤ 3n。直覺：第 \(2^j\) 次要付 \(2^j\)，前面 \(2^{j-1}+1\ldots2^j-1\) 這 \(2^{j-1}-1\) 次各存 $2，共 \(2^j-2\)，加上自己收的 $3 就夠。

(c) Potential\(\Phi(D_0)=0\)，\(\Phi(D_i)=2\bigl(i-2^{\lfloor\lg i\rfloor}\bigr)\ge0\)（距離上一個 2 的冪的兩倍）。

  • i 不是 2 的冪：\(\Delta\Phi=2\)，\(\hat c_i=1+2=3\)。
  • \(i=2^j\ (j\ge1)\)：\(\Phi(D_i)=0\)，\(\Phi(D_{i-1})=2(i-1-\tfrac i2)=i-2\)，\(\hat c_i=i+0-(i-2)=2\)。
  • \(i=1\)：\(\hat c_1=1+0-0=1\)。
故 \(\hat c_i\le3\)，\(\sum c_i\le\sum\hat c_i\le3n\)。

2020 Q6Φ = i − 2⌊lg i⌋ 為什麼不夠？怎麼改？10%

Suppose we perform a sequence of n operations on a data structure where the ith operation costs i if i is an exact power of 2, and 1 otherwise.
a. (4%) Use aggregate analysis to determine the total amortized cost in Big-Oh notation.
b. (4%) Using the potential method, show that the potential function Φ(Di) = i − 2⌊lg i⌋ cannot yield useful result.
c. (2%) Show how to modify Φ(Di) so that the potential method analysis gives the exact result.

同上的成本序列。(a) 用 aggregate 求總 amortized cost（Big-O）。(b) 用 potential method 說明 \(\Phi(D_i)=i-2^{\lfloor\lg i\rfloor}\) 得不到有用的結果。(c) 怎麼修改 Φ 才能得到正確結果。

詳解

(a) \(O(n)\)（見上題）。(b) 在 \(i=2^j\) 時 \(\hat c_i=1+i/2\)，不是常數。(c) 改成 \(\Phi'(D_i)=2(i-2^{\lfloor\lg i\rfloor})\)，\(\hat c_i\in\{3,2\}\)，總共 \(O(n)\)。

(b)非 2 的冪：\(\Delta\Phi=1\)，\(\hat c_i=1+1=2\)。\(i=2^j\)：\(\Phi(D_{i-1})=(i-1)-\tfrac i2=\tfrac i2-1\)，\(\hat c_i=i+0-(\tfrac i2-1)=1+\tfrac i2\)。每一段只存了約 \(i/2\)，付不起第 i 次的 i，所以 amortized cost 還含 i，得不到 \(O(1)\)。

(c)乘 2 之後非 2 的冪 \(\Delta\Phi'=2\)、\(\hat c=3\)；2 的冪 \(\Delta\Phi'=2-i\)、\(\hat c=2\)。\(\sum\hat c_i\le3n=O(n)\)。

直覺：從 \(2^{j-1}\) 到 \(2^j\) 中間只有約 \(2^{j-1}\) 個操作，要存夠 \(2^j\) 元，每個操作得存 2 元，不是 1 元。

In the dynamic table problem, if the table T is full before insertion of an item, we expand T by doubling its size and if table T is below (1/4)-full after deletion of an item, we contract table T by halving its size. We define a potential function Φ as follows: (a) If table T is at least half full Φ(T) = 2 num(T) – size(T). (b) If table T is less than half full Φ(T) = size(T)/2 – num(T). Please find the amortized cost of insertion and deletion.

Dynamic table：插入前若滿了就把 size 加倍；刪除後若少於 1/4 滿就減半。Φ 定義為：至少半滿時 \(2\,\text{num}-\text{size}\)，不到半滿時 \(\text{size}/2-\text{num}\)。求插入與刪除的 amortized cost。

詳解

INSERT：\(\hat c_i\le3\)；DELETE：\(\hat c_i\le2\)。都是 \(O(1)\)。

逐一列出上表 8 種情況的 \(c_i\)、\(\Phi_{i-1}\)、\(\Phi_i\)。兩個關鍵情況：

擴張\(\text{num}_{i-1}=\text{size}_{i-1}=s\)：\(\Phi_{i-1}=2s-s=s\)；插入後 num = s + 1、size = 2s：\(\Phi_i=2(s+1)-2s=2\)。\(\hat c_i=(s+1)+2-s=3\)。

收縮刪除前 \(\text{num}_{i-1}=\text{size}/4\)，刪後 \(\text{num}_i=\text{size}/4-1\)，size 變 size/2：\(\Phi_{i-1}=\text{size}/2-\text{size}/4=\text{size}/4\)，\(\Phi_i=\text{size}/4-\text{num}_i=1\)。\(\hat c_i=(1+\text{num}_i)+1-\text{size}/4=1\)。

2011 Q7從 b 個 1 開始，n = Ω(b) 時 O(n)10%

Suppose that a counter begins at a number with b 1s in its binary representation, rather than at 0. Show that the cost of performing n INCREMENT operations is O(n) if n = Ω(b). (Do not assume that b is constant.)

計數器一開始的二進位表示有 b 個 1（不是從 0 開始）。證明當 \(n=\Omega(b)\) 時，n 次 INCREMENT 的成本是 \(O(n)\)。（b 不能當常數。）

詳解

\(\Phi\) = 1 的個數，\(\hat c\le2\) ⇒ \(\sum c_i\le 2n-b_n+b\le2n+b\)；\(n=\Omega(b)\) 即 \(b\le cn\) ⇒ \(\le(2+c)n=O(n)\)。

Potential第 i 次 INCREMENT 把 \(t_i\) 個 1 變 0、至多 1 個 0 變 1：\(c_i\le t_i+1\)，\(\Delta\Phi\le1-t_i\)，\(\hat c_i\le2\)。\(\Phi(D_0)=b\)、\(\Phi(D_n)=b_n\ge0\)： $$\sum_{i=1}^{n}c_i=\sum\hat c_i-\Phi(D_n)+\Phi(D_0)\le 2n-b_n+b\le2n+b.$$ Since \(n=\Omega(b)\), \(\exists c>0\) with \(b\le cn\) for large n，所以總成本 \(\le(2+c)n=O(n)\)。∎

計數器除了 INCREMENT 還要能 RESET（全部歸零）。檢查或修改一個位元算 \(\Theta(1)\)，說明如何用位元陣列實作，使從 0 開始的任意 n 個 INCREMENT / RESET 共 \(O(n)\)。

詳解

記 A.max = 最高位 1 的 index；RESET 只清 A[0..max]。INCREMENT 收 $4、RESET 收 $1，存款不為負 ⇒ \(O(n)\)。

i = 0
while i < A.length and A[i] == 1
    A[i] = 0;  i = i + 1               // 用 bit 上的 credit 付
if i < A.length
    A[i] = 1                           // 收的 $4 之一付這裡
    if i > A.max  A.max = i            // $1 更新 max
else A.max = -1                        // overflow

for i = 0 to A.max
    A[i] = 0                           // 用每個位置存的 credit 付
A.max = -1

AccountingINCREMENT 收 $4：$1 把一個 bit 設成 1；$1 存在這個 bit 上，付它之後被清成 0（進位或 RESET）；$1 存給 RESET 檢查這個位置；$1 更新 max。RESET 收 $1（設 max = −1 等常數工作）。

Why上次 RESET 以來，0..max 的每個位置都至少被設成 1 一次（max 被設時，下面的位元剛因進位全部經過 1），所以每個位置都有 $1 付 RESET 的檢查。存款永不為負 ⇒ 總成本 \(\le4n=O(n)\)。

2018 給分：只有 pseudocode、沒有成本分析 4%；分析 8%（INCREMENT：set bit / credit / update max / examine 各 $1；RESET $1）；結論 2%。答案鍵文字寫 "$4 (作業筆誤)"，對照給分表是 $4。
