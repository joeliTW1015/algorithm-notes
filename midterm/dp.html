作答格式考卷開頭固定寫：If you design an algorithm, you must have a pseudo code … and analyze the time complexity in the worst case.
  • 設計 DP：定義子問題 → 遞迴式（含 base case）→ pseudocode（加註解）→ time / space。

  • 是非 / 觀念題：先寫結論，再寫理由；「只寫 True/False 不給分」。

DP 兩要素 + 不能用 DP 的例子

2012·13·22·23Two key ingredients of DP

What are the two key properties that an optimization problem must have in order for dynamic programming to apply? Please give an example that the dynamic programming cannot be applied.

一個最佳化問題要具備哪兩個關鍵性質，才能用動態規劃？請舉一個不能用動態規劃的例子。

2012 只問兩要素（5%）；2013、2022 加問反例（10%）；2023 問 "two key properties of the problems that DP can solve efficiently"（6%）。

詳解

(1) Optimal substructure　(2) Overlapping subproblems。反例：longest simple path。

  1. Optimal substructure：an optimal solution to the problem contains within it optimal solutions to subproblems.（問題的最佳解裡，子問題的解也是最佳的 → 可以寫成遞迴式。）
  2. Overlapping subproblems：a recursive algorithm revisits the same subproblem over and over; the number of distinct subproblems is small (polynomial).（同一個子問題被重複計算 → 存表只算一次。）

ExampleLongest simple path（unweighted directed graph）沒有 optimal substructure：

 q ⇄ r
 ↕   ↕      q→r→t 是 q 到 t 的最長簡單路徑，
 s ⇄ t      但子路徑 q→r 不是 q 到 r 的最長路徑（q→s→t→r 更長），
            r→t 也不是 r 到 t 的最長路徑（r→q→s→t 更長）。

Why兩個子問題的最長路徑會共用頂點（q→s→t→r 和 r→q→s→t 都用到 s、t），接起來 q→s→t→r→q→s→t 不是 simple path——子問題不 independent，最佳解不能由子問題最佳解組成，所以 DP 不能用。對照：shortest path 的子路徑一定是最短的（cut-and-paste），DP 可用。

2022 給分：overlapping 3%、optimal substructure 3%、反例 4%（要解釋為什麼不能用）。答案鍵另舉 n-queen，但 n-queen 不是最佳化問題，建議寫 longest simple path。

易錯：只寫名稱不寫意思會被扣分；反例只說「NP-hard」不算解釋。2013 答案鍵把兩個性質的說明寫成同一段（筆誤）。

詳解

Yes，仍有 optimal substructure：\(m[i,j]=\max_{i\le k

2011·21·25Longest monotonically increasing subsequence, O(n²)

Give an O(n²)-time algorithm to find the longest monotonically increasing subsequence of a sequence of n numbers.

給 \(O(n^2)\) 演算法，找出 n 個數的序列中最長的單調遞增子序列。（2021 版：A 是相異整數、只求長度、不必連續，例如 11, 17, 5, 8, 6, 4, 7, 12, 3 的 LIS 是 5, 6, 7, 12；要分析最壞時間與空間。）

2021 版：A[1..n] 是 distinct integers，只要長度；例子 11, 17, 5, 8, 6, 4, 7, 12, 3 → 5, 6, 7, 12；要分析 worst-case time 與 space（15%）。2011（10%）、2025（12%）同上題。

詳解

\(L[i]\) = 以 \(A[i]\) 結尾的最長遞增子序列長度；\(L[i]=1+\max(\{0\}\cup\{L[j]: j 

for i = 1 to n
    L[i] = 1;  prev[i] = NIL              // A[i] 自己一個
    for j = 1 to i - 1
        if A[j] < A[i] and L[j] + 1 > L[i]  // 接在 A[j] 後面
            L[i] = L[j] + 1;  prev[i] = j
best = argmax over i of L[i]              // O(n)
// 印出序列：從 best 沿 prev 往回走
return L[best]

Time內圈跑 \(i-1\) 次：\(\sum_{i=1}^{n}(i-1)=\frac{n(n-1)}{2}=O(n^2)\)；找最大值 \(O(n)\)。共 \(O(n^2)\)。SpaceL、prev 兩個陣列 \(O(n)\)。

ExampleA = 11, 17, 5, 8, 6, 4, 7, 12, 3 → L = 1, 2, 1, 2, 2, 1, 3, 4, 1，最大 4：5, 6, 7, 12。

易錯：定義成「前 i 個的 LIS 長度」不知道最後一個數是誰，無法判斷能不能接——一定要「以 i 結尾」。加分：維護 tails 陣列 + binary search 可做到 \(O(n\lg n)\)。

        for t = 0 to j                 // 專案 i 拿 t 個
            if X[i-1, j-t] + P(i, t) > X[i, j]
                X[i, j] = X[i-1, j-t] + P(i, t);  T[i, j] = t
return X[n, m]   // 分配：j = m; for i = n downto 1: print T[i, j]; j = j - T[i, j]
