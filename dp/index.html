海盜分金 & 外遇村

倒推法與歸納法：DP 思維的另一個樣子。

設計 DP 的四個步驟

  1. 定義子問題：找出 optimal substructure——做一個選擇之後，剩下的是哪些「同類型、更小」的問題？
  2. 寫遞迴式：最佳值 = 在所有選擇中取 max / min（子問題的最佳值 + 這個選擇的成本），別忘了 base case。
  3. 決定計算順序：bottom-up 讓被依賴的格子先填；或用 memoization 讓遞迴自己決定。
  4. 還原解：另存每個子問題的最佳選擇（\(s\)、\(b\)、\(root\) 表），最後從答案那格往回追。

考前檢查清單

  • 能用一句話定義子問題，並說明「做了什麼選擇、剩下哪些子問題」。
  • 能寫出完整遞迴式，包括 base case。
  • 能用 cut-and-paste 論證 optimal substructure。
  • 能手動填一張小表，並回溯出解（括號、LCS 字串、BST 結構、切法）。
  • 能分析時間：子問題數 × 每個子問題的選擇數；能說明直接遞迴為什麼是指數級（寫出 \(T(n)\) 遞迴式並代入）。
  • 能分辨 memoization 和 bottom-up，各自的優缺點。
  • 能舉出貪婪法失敗的反例（14.1-2、14.3-4），以及沒有 optimal substructure 的例子（最長簡單路徑、14.3-5）。
