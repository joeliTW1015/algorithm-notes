Practice & 作業詳解

每一題都照同一套流程寫：定義子問題 → 遞迴式（含 base case）→ pseudocode → 時間 / 空間。先自己想過遞迴式，再看解答。

作答格式依 2026 第一次小考的給分標準：設計演算法要有 pseudocode（加註解）和 worst-case time（逐段算再加總）；沒有理由或計算過程不給分。

壽司：價格遞增、總價最大

Practice at Home · Lecture 14-1

題目Peter 的壽司店有 \(n\) 盤壽司排成一列，價格都不同。你要由左到右挑選，而且每次挑的下一盤必須比上一盤貴。設計 \(O(n^2)\) 演算法讓總價最大。

Subproblem\(S[i]\) = 最後一盤是第 \(i\) 盤時的最大總價（固定結尾，才知道下一盤能不能接）。

Recurrence前一盤不存在，或是某個 \(j\lt i,\ c_j\lt c_i\)： $$S[i]=c_i+\max\bigl(\{0\}\cup\{S[j]: j\lt i,\ c_j\lt c_i\}\bigr),\qquad\text{answer}=\max_i S[i].$$

for i = 1 to n
    S[i] = c[i];  prev[i] = NIL               // 只拿第 i 盤
    for j = 1 to i - 1
        if c[j] < c[i] and S[j] + c[i] > S[i]   // 接在第 j 盤後面
            S[i] = S[j] + c[i];  prev[i] = j
best = argmax_i S[i]
return S[best]        // 從 best 沿 prev 回溯出要拿的盤

Time\(\sum_{i=1}^{n}(i-1)=\frac{n(n-1)}{2}=O(n^2)\)；空間 \(O(n)\)。

易錯：「\(S[i]\) = 前 \(i\) 盤的最佳解」不知道最後一盤多貴，無法判斷下一盤能不能接。

爬樓梯：一次 1、2 或 3 階

Practice at Home · Lecture 14-1

題目樓梯有 \(n\) 階，Jack 一步可以走 1、2 或 3 階。令 \(F_k\) 為走上 \(k\) 階的方法數，寫出 \(F_k\) 的遞迴式，並說明 \(F_n\) 可以在 \(O(n)\) 時間算出。（投影片題目中途把 Jack 寫成 John，是同一個人。）

\(F_k=F_{k-1}+F_{k-2}+F_{k-3}\ (k\ge3)\)，\(F_0=1,\ F_1=1,\ F_2=2\)。

Why看最後一步走 1、2 或 3 階：三種情況互斥且涵蓋所有走法，最後一步走 \(m\) 階有 \(F_{k-m}\) 種。

F[0] = 1;  F[1] = 1;  F[2] = 2
for k = 3 to n
    F[k] = F[k - 1] + F[k - 2] + F[k - 3]   // 最後一步 1 / 2 / 3 階
return F[n]

Time迴圈 \(n-2\) 次，每次 \(O(1)\) → \(O(n)\)（只留最後三個值則空間 \(O(1)\)）。直接遞迴會重複算同樣的子問題，呼叫數指數成長。

最長遞增子序列（LIS）

Practice at Home · Lecture 14-1（也是課本習題 14.4-5）

題目\(A[1..n]\) 是 \(n\) 個相異整數，求最長遞增子序列的長度（不必連續）。例：11, 17, 5, 8, 6, 4, 7, 12, 3 的 LIS 是 5, 6, 7, 12。分析最壞情況的時間與空間。

Subproblem\(L[i]\) = 以 \(A[i]\) 結尾的最長遞增子序列長度。

Recurrence\(L[i]=1+\max\bigl(\{0\}\cup\{L[j]: j\lt i,\ A[j]\lt A[i]\}\bigr)\)，answer \(=\max_i L[i]\)。

for i = 1 to n
    L[i] = 1;  prev[i] = NIL
    for j = 1 to i - 1
        if A[j] < A[i] and L[j] + 1 > L[i]   // 接在 A[j] 後面更長
            L[i] = L[j] + 1;  prev[i] = j
return max_i L[i]       // 沿 prev 回溯可印出序列

Time雙層迴圈固定比較 \(n(n-1)/2\) 次 → \(\Theta(n^2)\)；空間 \(L, prev\) → \(\Theta(n)\)。

\(i\)123456789
\(A[i]\)111758647123
\(L[i]\)121221341

\(L[8]=4\) 最大，回溯 \(12\leftarrow7\leftarrow6\leftarrow5\)：LIS = 5, 6, 7, 12。

另解：LIS = LCS\((A, \text{sorted }A)\)，\(O(n^2)\)；課本 14.4-6 有 \(O(n\lg n)\) 的二分搜尋版本。

作業 1：樹上的最大權重獨立集

Homework · Lecture 14-2

題目\(G=(V,E)\) 是一棵樹（連通、無環的無向圖），每個頂點有正權重 \(w(i)\)。\(I\subseteq V\) 是 independent set 若 \(I\) 中任兩點都不相鄰；\(w(I)=\sum_{i\in I}w(i)\)。用 DP 找出最大權重獨立集。

Subproblem任選 root。對每個點 \(v\)（子樹 \(T_v\)）：\(in(v)\) = 選 \(v\) 時 \(T_v\) 的最大權重；\(out(v)\) = 不選 \(v\) 時的最大權重。

Recurrence\(C(v)\) = \(v\) 的小孩： $$in(v)=w(v)+\sum_{c\in C(v)}out(c),\qquad out(v)=\sum_{c\in C(v)}\max\{in(c),out(c)\}.$$ 葉子：\(in=w(v)\)、\(out=0\)。answer \(=\max\{in(root),out(root)\}\)。

Why選了 \(v\)，小孩都不能選；不選 \(v\)，各小孩的子樹互不相鄰，可以獨立取最好（子問題獨立）。

in = w(v);  out = 0
for each child c of v
    (ci, co) = TREE-MWIS(c)   // post-order：小孩先算
    in  = in + co             // 選了 v，c 不能選
    out = out + max(ci, co)   // 沒選 v，c 自由選
return (in, out)

Time每個點做一次，工作量 \(\propto\) 小孩數，加總 = 邊數 \(n-1\) → \(O(n)\)。還原：由 root 往下，父節點被選則自己不選，否則看 \(in(v)\ge out(v)\)。

易錯：「隔層選」或「先選權重最大的點」都不一定最佳（下面按「隨機產生」可看到反例）。

作業 2：k × n 棋盤鋪 k × 1 長條

Homework · Lecture 14-2

題目用 \(n\) 個 \(k\times1\) 或 \(1\times k\) 的長條完全覆蓋 \(k\times n\) 的棋盤（\(k\) 列、\(n\) 行），有幾種方法？例如 \(k=2, n=3\) 有 3 種：(a) 最左行直放、其餘兩條橫放；(b) 最右行直放、其餘橫放；(c) 每一行都直放。設計 \(O(n)\) 演算法。

\(f(n)=f(n-1)+f(n-k)\ (n\ge k)\)，\(f(0)=\dots=f(k-1)=1\)（\(k\ge2\)）。

Why看最左邊那一行：

  • 一條直放蓋滿 → 剩 \(k\times(n-1)\)。
  • 否則有格子被橫條蓋住，橫條從這行往右延伸 \(k\) 格；這行不能再放直條，所以 \(k\) 格全是橫條，疊成 \(k\times k\) 方塊 → 剩 \(k\times(n-k)\)。

兩種情況互斥。\(n\lt k\) 時橫條放不下，只有全直放 1 種。驗證 \(k=2\)：\(f(2)=2,\ f(3)=3\) ✓。

if k == 1
    return 1                  // 1×1 只有一種鋪法
let f[0:n] be a new array
for i = 0 to n
    if i < k
        f[i] = 1              // 只能全部直放
    else f[i] = f[i - 1] + f[i - k]   // 最左行直放 / k×k 橫條方塊
return f[n]

Time迴圈 \(n+1\) 次，每次 \(O(1)\) → \(O(n)\)；只留最後 \(k\) 個值則空間 \(O(k)\)。
