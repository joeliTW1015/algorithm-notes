投影片上的 Practice at Home 與 Homework

Practice & 作業詳解

每一題都照同一套流程解：定義子問題 → 寫遞迴式（含 base case）→ 決定填表順序 → 分析時間空間 → 還原解。先自己想過遞迴式，再展開解答會比較有效。

壽司：價格遞增、總價最大

Practice at Home · Lecture 14-1

題目Peter 的壽司店有 \(n\) 盤壽司排成一列，價格都不同。你要由左到右挑選，而且每次挑的下一盤必須比上一盤貴。設計 \(O(n^2)\) 演算法讓總價最大。

換句話說：在序列 \(c_1,\dots,c_n\) 中找一個嚴格遞增的子序列，使元素和最大（maximum-sum increasing subsequence）。

  1. 子問題：\(S[i]\) = 「最後一盤是第 \(i\) 盤」的所有合法選法中，總價的最大值。關鍵是固定結尾：知道最後一盤是誰，才能判斷下一盤能不能接。
  2. 遞迴式：第 \(i\) 盤前面那一盤，要嘛不存在（只拿 \(i\)），要嘛是某個 \(j<i\) 且 \(c_j<c_i\)： $$S[i]=c_i+\max\bigl(\{0\}\cup\{\,S[j] : j\lt i,\ c_j\lt c_i\,\}\bigr)$$
  3. Optimal substructure：若最佳選法是 \(\dots, j, i\)，那拿掉 \(i\) 後的部分必須是「以 \(j\) 結尾」的最佳選法，否則換掉就更好（cut-and-paste）。
  4. 順序：\(i=1,2,\dots,n\)（\(S[i]\) 只依賴左邊的 \(S[j]\)）。答案是 \(\max_i S[i]\)（最後一盤可以是任何一盤）。
  5. 時間：每個 \(i\) 檢查 \(i-1\) 個 \(j\)，共 \(\sum (i-1)=n(n-1)/2=O(n^2)\)。空間 \(O(n)\)。另存 \(prev[i]\)（取到最大值的 \(j\)）就能回溯出要拿哪些盤。
for i = 1 to n
    S[i] = c[i];  prev[i] = NIL     // 只拿第 i 盤
    for j = 1 to i - 1
        if c[j] < c[i] and S[j] + c[i] > S[i]
            S[i] = S[j] + c[i];  prev[i] = j
best = argmax_i S[i]
return S[best] and trace prev[] back from best
常見錯誤用「\(S[i]\) = 前 \(i\) 盤裡的最佳解」當子問題會卡住：你不知道那個最佳解最後一盤多貴，就沒辦法判斷第 \(i+1\) 盤能不能接上。定義子問題時要把「接下來的決策需要知道的資訊」放進去。

爬樓梯：一次 1、2 或 3 階

Practice at Home · Lecture 14-1

題目樓梯有 \(n\) 階，Jack 一步可以走 1、2 或 3 階。令 \(F_k\) 為走上 \(k\) 階的方法數，寫出 \(F_k\) 的遞迴式，並說明 \(F_n\) 可以在 \(O(n)\) 時間算出。（投影片題目中途把 Jack 寫成 John，是同一個人。）
  1. 看最後一步：走上第 \(k\) 階的最後一步，一定是 1、2 或 3 階其中之一。這三種情況互斥且涵蓋所有走法。
  2. 每種情況的數量：最後一步走 \(m\) 階 ⇔ 先用任意方式走到第 \(k-m\) 階，有 \(F_{k-m}\) 種。
  3. 遞迴式（加法原理）： $$F_k=F_{k-1}+F_{k-2}+F_{k-3}\quad(k\ge3),\qquad F_0=1,\ F_1=1,\ F_2=2$$ （\(F_0=1\) 代表「已經在地面、不用走」這一種；有了它，\(F_1=F_0\)、\(F_2=F_1+F_0\) 也符合同一個式子。）
  4. \(O(n)\)：由 \(k=3\) 算到 \(n\)，每個 \(F_k\) 是三個已知值相加，\(O(1)\)，總共 \(O(n)\)。只需要保留最後三個值，空間 \(O(1)\)。
  5. 為什麼不能直接遞迴：直接遞迴的呼叫數本身就滿足類似的遞迴式，會指數成長（\(\approx 1.84^n\)）；因為 \(F_{k-1}, F_{k-2}, F_{k-3}\) 又會重複呼叫同樣的子問題——典型的 overlapping subproblems。

最長遞增子序列（LIS）

Practice at Home · Lecture 14-1（也是課本習題 14.4-5）

題目\(A[1..n]\) 是 \(n\) 個相異整數，求最長遞增子序列的長度（不必連續）。例：11, 17, 5, 8, 6, 4, 7, 12, 3 的 LIS 是 5, 6, 7, 12。分析最壞情況的時間與空間。
  1. 子問題：\(L[i]\) = 以 \(A[i]\) 結尾的最長遞增子序列長度（和壽司題同樣的技巧）。
  2. 遞迴式： $$L[i]=1+\max\bigl(\{0\}\cup\{\,L[j]: j\lt i,\ A[j]\lt A[i]\,\}\bigr)$$
  3. 答案：\(\max_{1\le i\le n}L[i]\)。用 \(prev[i]\) 記錄接在誰後面，就能印出序列。
  4. 時間：雙層迴圈，最壞 \(\Theta(n^2)\)（不管輸入長怎樣都要比較 \(n(n-1)/2\) 次）。空間：\(L\) 與 \(prev\) 兩個陣列，\(\Theta(n)\)。

例子的表：

\(i\)123456789
\(A[i]\)111758647123
\(L[i]\)121221341

\(L[8]=4\) 最大，沿 \(prev\) 回溯：\(12\leftarrow7\leftarrow6\leftarrow5\)，所以 LIS = 5, 6, 7, 12。（\(L[7]=3\) 也可以從 5, 6 或 4 接上來，最長的是接在 \(A[5]=6\) 後面。）

其他解法(1) 把 \(A\) 排序得到 \(A'\)，LIS = LCS\((A, A')\)，\(O(n^2)\)。(2) 課本 14.4-6 的 \(O(n\lg n)\)：維護「長度為 \(k\) 的遞增子序列最小可能的結尾」陣列，它是遞增的，可以二分搜尋。

作業 1：樹上的最大權重獨立集

Homework · Lecture 14-2

題目\(G=(V,E)\) 是一棵樹（連通、無環的無向圖），每個頂點有正權重 \(w(i)\)。\(I\subseteq V\) 是 independent set 若 \(I\) 中任兩點都不相鄰；\(w(I)=\sum_{i\in I}w(i)\)。用 DP 找出最大權重獨立集。
  1. 先把樹變成有根樹：任選一點當 root，每個點 \(v\) 有自己的子樹 \(T_v\)。子問題就是「\(T_v\) 裡的最佳獨立集」。
  2. 需要知道 \(v\) 有沒有被選（因為它決定了小孩能不能選），所以每個點算兩個值：
    • \(in(v)\)：\(v\) 在獨立集中時，\(T_v\) 的最大權重；
    • \(out(v)\)：\(v\) 不在獨立集中時，\(T_v\) 的最大權重。
  3. 遞迴式（\(C(v)\) = \(v\) 的小孩們）： $$in(v)=w(v)+\sum_{c\in C(v)}out(c),\qquad out(v)=\sum_{c\in C(v)}\max\{\,in(c),\ out(c)\,\}$$ 葉子：\(in(v)=w(v)\)、\(out(v)=0\)。答案：\(\max\{in(root), out(root)\}\)。
  4. 正確性：選了 \(v\)，所有小孩都不能選；但孫子不受 \(v\) 影響，交給 \(out(c)\) 處理。沒選 \(v\)，小孩們之間互不相鄰（樹上兄弟之間沒有邊），每棵子樹可以獨立取最好的情況——子問題互相獨立，所以 optimal substructure 成立。
  5. 順序與時間：用 post-order（DFS 回來時才算）保證小孩先算好。每個點的工作量和它的小孩數成正比，加總 = 邊數 = \(n-1\)，所以 \(O(n)\)。
  6. 還原解：從 root 往下：若父節點被選，自己不能選；否則看 \(in(v)\ge out(v)\) 決定選不選。
in = w(v);  out = 0
for each child c of v
    (ci, co) = TREE-MWIS(c)
    in  = in + co             // 選了 v，c 不能選
    out = out + max(ci, co)   // 沒選 v，c 自由選
return (in, out)
陷阱「隔層選」（選所有偶數層或所有奇數層）不一定最佳，貪婪地「先選權重最大的點」也不一定最佳。用上面的「隨機產生」多試幾棵樹就能看到反例。

作業 2：k × n 棋盤鋪 k × 1 長條

Homework · Lecture 14-2

題目用 \(n\) 個 \(k\times1\) 或 \(1\times k\) 的長條完全覆蓋 \(k\times n\) 的棋盤（\(k\) 列、\(n\) 行），有幾種方法？例如 \(k=2, n=3\) 有 3 種：(a) 最左行直放、其餘兩條橫放；(b) 最右行直放、其餘橫放；(c) 每一行都直放。設計 \(O(n)\) 演算法。
  1. 看最左邊那一行（\(k\) 個格子）。它只能用兩種方式覆蓋：
    • 一條直放（\(k\times1\)）蓋滿這一行 → 剩下 \(k\times(n-1)\)。
    • 橫放：只要這一行有一格是被橫條蓋住，因為它是最左行，那條橫條就從這行開始往右延伸 \(k\) 格。這一行其他格子也不能再放直條（直條要佔滿整行），所以這一行的 \(k\) 格全都是橫條，\(k\) 條橫條疊成一個 \(k\times k\) 方塊 → 剩下 \(k\times(n-k)\)。
  2. 遞迴式（兩種情況互斥）： $$f(n)=f(n-1)+f(n-k)\quad(n\ge k),\qquad f(0)=f(1)=\cdots=f(k-1)=1$$ （\(n<k\) 時橫條放不下，只能全部直放，1 種；\(f(0)=1\) 是空棋盤。）
  3. 驗證：\(k=2\)：\(f(0)=f(1)=1,\ f(2)=2,\ f(3)=f(2)+f(1)=3\) ✓（\(k=2\) 時就是 Fibonacci）。
  4. \(O(n)\)：由 \(f(k)\) 算到 \(f(n)\)，每項一次加法。只保留最後 \(k\) 個值的話，空間 \(O(k)\)。
  5. 特例：\(k=1\) 時直條和橫條都是 \(1\times1\)，只有 1 種鋪法，不能套用遞迴式（會重複計算成 \(2^n\)）。
if k == 1
    return 1
let f[0:n] be a new array
for i = 0 to n
    if i < k
        f[i] = 1
    else f[i] = f[i - 1] + f[i - k]
return f[n]
