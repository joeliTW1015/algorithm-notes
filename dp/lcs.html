Lecture 14-3 · Dynamic Programming III

Longest Common Subsequence

兩個字串最長的共同子序列（LCS）。子問題是「兩個前綴」，表格是二維的 \((m+1)\times(n+1)\)，每格只看左、上、左上三個鄰居，總共 \(\Theta(mn)\)。

什麼是 subsequence？

設 \(S=s_1s_2\cdots s_m\)。任何形如 \(s_{i_1}s_{i_2}\cdots s_{i_k}\)、且 \(i_1<i_2<\cdots<i_k\) 的字串都是 \(S\) 的 subsequence：從 \(S\) 刪掉一些字元、保持剩下字元的順序，不要求連續。

例：\(S=\) farmers，則 fame、arm、mrs、farmers 都是 \(S\) 的 subsequence。

別搞混Substring（子字串）要求連續；subsequence（子序列）不用連續。“arm” 在 farmers 中兩者皆是；“fame” 只是 subsequence。

Longest common subsequence

  • 若一個字串同時是 \(S\) 和 \(T\) 的 subsequence，它就是 \(S, T\) 的 common subsequence。
  • 其中最長的就是 longest common subsequence (LCS)。LCS 可能不只一個。

例：\(S=\) algorithms、\(T=\) logarithms。aim、lots、ohms、grit 都是 common subsequence；最長的是 lorithms 和 lgrithms（長度 8）。

暴力法：\(S\) 有 \(2^m\) 個 subsequence，每個花 \(O(n)\) 檢查是否也是 \(T\) 的 subsequence → \(O(n2^m)\)，太慢。

Optimal substructure

記號：\(S_{1,i}=s_1\cdots s_i\)（\(S\) 的長度 \(i\) 前綴），\(T_{1,j}=t_1\cdots t_j\)。

Lemma設 \(X=x_1x_2\cdots x_k\) 是 \(S_{1,i}\) 和 \(T_{1,j}\) 的一個 LCS。
  • 若 \(s_i=t_j\)：則 \(x_k=s_i=t_j\)，且 \(x_1\cdots x_{k-1}\) 是 \(S_{1,i-1}\) 和 \(T_{1,j-1}\) 的 LCS。
  • 若 \(s_i\ne t_j\)：則 \(X\) 是 (i) \(S_{1,i}\) 與 \(T_{1,j-1}\) 的 LCS，或 (ii) \(S_{1,i-1}\) 與 \(T_{1,j}\) 的 LCS。

證明

  1. \(s_i=t_j\) 時 \(x_k=s_i\)：如果 \(x_k\ne s_i\)，把 \(s_i\)（\(=t_j\)）接在 \(X\) 後面，得到長度 \(k+1\) 的 common subsequence，和 \(X\) 最長矛盾。
  2. 前面 \(k-1\) 個是子問題的 LCS：\(x_1\cdots x_{k-1}\) 顯然是 \(S_{1,i-1}, T_{1,j-1}\) 的 common subsequence。若那兩個前綴有更長（\(\ge k\)）的 common subsequence \(W\)，則 \(W\) 接上 \(s_i\) 長度 \(\ge k+1\)，矛盾（cut-and-paste）。
  3. \(s_i\ne t_j\) 時：\(x_k\) 不可能同時等於 \(s_i\) 和 \(t_j\)。若 \(x_k\ne s_i\)，\(X\) 根本沒用到 \(s_i\)，所以 \(X\) 是 \(S_{1,i-1}, T_{1,j}\) 的 common subsequence；它也必須是最長的，否則換掉就能讓原本的 LCS 更長。\(x_k\ne t_j\) 的情況對稱。

遞迴式

令 \(len_{i,j}\)（課本記作 \(c[i,j]\)）為 \(S_{1,i}\) 和 \(T_{1,j}\) 的 LCS 長度：

$$len_{i,j}=\begin{cases}0 & i=0 \text{ 或 } j=0\\[2pt] len_{i-1,j-1}+1 & i,j\ge1 \text{ 且 } s_i=t_j\\[2pt] \max\{\,len_{i,j-1},\; len_{i-1,j}\,\} & i,j\ge1 \text{ 且 } s_i\ne t_j\end{cases}$$

直接遞迴

if i == 0 or j == 0
    return 0                // base case
if s_i == t_j
    return Compute_L(i-1, j-1) + 1
else
    return max{Compute_L(i-1, j), Compute_L(i, j-1)}
  • 最壞情況每次呼叫都分成兩支，深度最多 \(m+n\) → \(O(2^{m+n})\)。
  • Overlapping subproblems：\(\text{Compute\_L}(i, j-1)\) 和 \(\text{Compute\_L}(i-1, j)\) 都會呼叫 \(\text{Compute\_L}(i-1, j-1)\)，重複非常多。但不同的子問題只有 \((m+1)(n+1)\) 個。

Bottom-up：一列一列填

for all i and j, set L[i, 0] = L[0, j] = 0
for i = 1 to m
    compute L[i, j] for all j = 1..n
    // 只用到 L[i-1, j-1], L[i-1, j], L[i, j-1]
return L[m, n]

每格 \(O(1)\)，共 \((m+1)(n+1)\) 格 → \(\Theta(mn)\)。下面是投影片的例子：\(S=\) DIRTYROOM（\(m=9\)，列），\(T=\) DORMITORY（\(n=9\)，行）。表格同時填數字（\(c\) 表）和箭頭（\(b\) 表）。可以改成任何字串：

箭頭的意義（\(b\) 表）

  • ↖：\(x_i=y_j\)，這個字元屬於 LCS，往左上 \((i-1,j-1)\) 走。
  • ↑：答案來自上面 \(c[i-1,j]\)（丟掉 \(x_i\)）。
  • ←：答案來自左邊 \(c[i,j-1]\)（丟掉 \(y_j\)）。
  • 從 \(c[m,n]\) 沿箭頭走回邊界，把 ↖ 格子的字元倒過來讀，就是一個 LCS。時間 \(O(m+n)\)。
投影片對照投影片最後的回溯圖得到 DITY；照課本虛擬碼（平手時用 ≥ 走 ↑）回溯會得到 DIRY。兩個都是長度 4 的 LCS（這題共有 DIRY、DITO、DITR、DITY、DRTO、DRTR、DRTY 七個）。差別在平手時的方向：投影片的箭頭表有 5 格（\(b[4,8], b[4,9], b[5,7], b[5,8], b[9,6]\)）上方和左方都是 3，卻畫成 ←，和其他格「平手往 ↑」的規則不一致。考試時照虛擬碼的規則畫即可，並說明平手的處理方式。

完整虛擬碼

m = X.length
n = Y.length
for i = 1 to m
    c[i, 0] = 0
for j = 0 to n
    c[0, j] = 0
for i = 1 to m
    for j = 1 to n
        if x_i == y_j
            c[i, j] = c[i-1, j-1] + 1
            b[i, j] = "↖"
        elseif c[i-1, j] ≥ c[i, j-1]   // 也可用 >
            c[i, j] = c[i-1, j]
            b[i, j] = "↑"
        else c[i, j] = c[i, j-1]
            b[i, j] = "←"
return c and b

if i == 0 or j == 0
    return                  // LCS 是空的
if b[i, j] == "↖"
    PRINT-LCS(b, X, i-1, j-1)
    print x_i               // 遞迴回來後才印 → 順序正確
elseif b[i, j] == "↑"
    PRINT-LCS(b, X, i-1, j)
else PRINT-LCS(b, X, i, j-1)

第 12 行用 ≥ 或 > 都正確，只會影響平手時選哪個方向，也就是會印出哪一個 LCS。

延伸

  • 不用 \(b\) 表也能回溯：在 \((i,j)\) 時直接比較 \(x_i, y_j\) 和 \(c\) 的鄰居就知道從哪來，見習題 14.4-2。
  • Memoized 版本：在 Compute_L 加查表，只算需要的格子，\(O(mn)\)，見習題 14.4-3。
  • 省空間：如果只要長度，算第 \(i\) 列只需要第 \(i-1\) 列，只保留兩列（甚至一列加一個變數）即可，空間 \(O(\min(m,n))\)。
  • LIS：最長遞增子序列可以化成 LCS（把序列和排序後的自己做 LCS），也可以直接 DP，見Practice 和習題 14.4-5。
