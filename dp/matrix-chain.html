Matrix-Chain Multiplication 矩陣鏈乘

連乘 \(A_1A_2\cdots A_n\) 時，括號怎麼加不影響答案，卻可能讓計算量差上百倍。目標：找出乘法次數最少的括號方式。這是第一個「區間型」DP：子問題是一段連續的區間 \([i, j]\)。

兩個矩陣相乘要幾次乘法？

  • \(A\) 是 \(p\times q\)、\(B\) 是 \(q\times r\)，則 \(C=AB\) 是 \(p\times r\)。
  • \(C\) 的每一格是「\(A\) 的一列」和「\(B\) 的一行」做內積，要 \(q\) 次乘法。
  • \(C\) 有 \(pr\) 格，所以總共 \(pqr\) 次純量乘法。

投影片的例子：\(A\) 是 \(2\times 3\)、\(B\) 是 \(3\times 2\)，那 \(c_{1,2}\) 怎麼算？取 \(A\) 第 1 列和 \(B\) 第 2 行：

$$c_{1,2}=a_{1,1}b_{1,2}+a_{1,2}b_{2,2}+a_{1,3}b_{3,2}$$

3 次乘法（\(q=3\)），而 \(C\) 有 \(2\times2=4\) 格，總共 \(2\cdot3\cdot2=12\) 次。

結合律：括號不影響結果，但影響成本

矩陣乘法滿足結合律 \(((A_1A_2)A_3)=(A_1(A_2A_3))\)，所以任何括號方式算出來都一樣。例如 4 個矩陣有 5 種：

(A1((A2A3)A4)) = (A1(A2(A3A4))) = ((A1A2)(A3A4)) = (((A1A2)A3)A4) = ((A1(A2A3))A4)

為什麼要在意？不同的計算順序，乘法次數可能差很多。投影片的例子：\(A_1, A_2, A_3\) 分別是 \(1\times100\)、\(100\times1\)、\(1\times100\)：

  • \(((A_1A_2)A_3)\)：先算 \(A_1A_2\)，\(1\cdot100\cdot1=100\) 次，得到 \(1\times1\)；再乘 \(A_3\)，\(1\cdot1\cdot100=100\) 次。共 200 次。
  • \((A_1(A_2A_3))\)：先算 \(A_2A_3\)，\(100\cdot1\cdot100=10{,}000\) 次，得到 \(100\times100\)；再算 \(A_1\) 乘它，\(1\cdot100\cdot100=10{,}000\) 次。共 20,000 次，是前者的 100 倍。

有幾種括號方式？Catalan number

令 \(P(n)\) 為 \(n\) 個矩陣的括號方式數。最外層一定是把 \(A_1\cdots A_k\) 和 \(A_{k+1}\cdots A_n\) 相乘，左邊 \(P(k)\) 種、右邊 \(P(n-k)\) 種：

$$P(n)=\begin{cases}1 & n=1\\[2pt]\displaystyle\sum_{k=1}^{n-1}P(k)\,P(n-k) & n\ge2\end{cases} \;=\;\frac{1}{n}\binom{2n-2}{n-1}\;=\;\Omega\!\left(\frac{4^n}{n^{3/2}}\right)$$
\(n\)123456781015
\(P(n)\)1125144213242948622674440

\(P(n)\) 就是第 \(n-1\) 個 Catalan number。暴力法把每一種括號都試一遍（每種的成本頂多算一次），時間是 \(O\!\left(\binom{2n-2}{n-1}/n\right)\)，指數級。

Optimal substructure

Lemma假設乘 \(B_1B_2\cdots B_n\) 的最佳方式是：(i) 先算 \(B_1\cdots B_x\)，(ii) 再算 \(B_{x+1}\cdots B_n\)，(iii) 最後把兩者相乘。那麼 (i) 和 (ii) 也必須各自用最少的乘法次數算出來。

證明（cut-and-paste）：總成本 = (i) 的成本 + (ii) 的成本 + 最後一次相乘的成本。最後一次的成本只和維度有關，跟 (i)、(ii) 內部怎麼加括號無關。如果 (i) 有更便宜的算法，把它換進來，總成本就會變小，和「最佳」矛盾。(ii) 同理。∎

寫出遞迴式

令 \(f_{i,j}\)（課本記作 \(m[i,j]\)）為算出 \(A_iA_{i+1}\cdots A_j\) 的最少乘法次數；\(A_k\) 是 \(r_k\times c_k\)，用課本的記法就是 \(p_{k-1}\times p_k\)，所以 \(r_i c_k c_j = p_{i-1}p_kp_j\)。

$$f_{i,j}=\begin{cases}0 & i=j\\[2pt]\displaystyle\min_{i\le k\lt j}\bigl\{\,f_{i,k}+f_{k+1,j}+p_{i-1}\,p_k\,p_j\,\bigr\} & i\lt j\end{cases}$$
  • \(k\) 是「最後一次相乘」的分割點：左邊是 \(A_i\cdots A_k\)（\(p_{i-1}\times p_k\)），右邊是 \(A_{k+1}\cdots A_j\)（\(p_k\times p_j\)）。
  • 兩者相乘的成本是 \(p_{i-1}\,p_k\,p_j\)。
  • 對每個 \(k\) 都試一次，取最小值。

直接遞迴：指數時間

if i == j
    return 0
m[i, j] = ∞
for k = i to j - 1
    g = Compute_F(i, k) + Compute_F(k+1, j) + p[i-1]·p[k]·p[j]
    if g < m[i, j]
        m[i, j] = g
return m[i, j]

if i == j
    return 0
m[i, j] = ∞
for k = i to j - 1
    q = RMC(p, i, k) + RMC(p, k+1, j) + p[i-1]·p[k]·p[j]
    if q < m[i, j]
        m[i, j] = q
return m[i, j]

為什麼是 \(\Omega(2^n)\)？（substitution method，也是習題 14.2-3）

令 \(T(n)\) 為 RMC 處理 \(n\) 個矩陣所需時間（每行程式至少花 1 單位）。

  1. 列出遞迴式：第 1–3 行花 1，迴圈每一圈遞迴兩次再加 1： $$T(1)\ge1,\qquad T(n)\ge 1+\sum_{k=1}^{n-1}\bigl(T(k)+T(n-k)+1\bigr)\quad(n>1)$$
  2. 整理：\(k\) 跑過 \(1\dots n-1\) 時，\(T(k)\) 和 \(T(n-k)\) 都恰好把 \(T(1),\dots,T(n-1)\) 各列一次；常數項是 \(1+(n-1)=n\)： $$T(n)\ge 2\sum_{i=1}^{n-1}T(i)+n$$
  3. 猜答案：\(T(n)\ge 2^{n-1}\)。Base case：\(T(1)\ge1=2^0\) ✓。
  4. 代入：假設對所有 \(i<n\) 成立， $$T(n)\ge 2\sum_{i=1}^{n-1}2^{i-1}+n = 2(2^{n-1}-1)+n = 2^n+n-2 \ge 2^{n-1}.$$
  5. 結論：\(T(n)\ge 2^{n-1}\)，所以 \(T(n)=\Omega(2^n)\)。

Overlapping subproblems

算 \(f_{i,j}\) 和 \(f_{i,j+1}\) 時，兩者都需要 \(f_{i,i}, f_{i,i+1},\dots,f_{i,j-1}\)，這些子問題被重複計算。但不同的子問題只有 \(\binom{n}{2}+n=\Theta(n^2)\) 個（每對 \(1\le i\le j\le n\) 一個）。子問題少、重複多，正是 DP 的時機。

Bottom-up：依 chain length 由短到長

觀察：\(f_{i,j}\) 只依賴「更短」的區間 \(f_{x,y}\)（\(y-x < j-i\)）。所以先填所有長度 1 的區間（對角線，全是 0），再填長度 2、長度 3……最後是長度 \(n\) 的 \(f_{1,n}\)。

n = p.length - 1        // A_i 是 p[i-1] × p[i]
for i = 1 to n
    F[i, i] = 0
for length = 1 to n - 1
    for i = 1 to n - length
        compute F[i, i+length]   // Θ(n)
        // 只用到 |x-y| < length 的 F[x, y]
return F[1, n]

為什麼是 \(\Theta(n^3)\)？

  • 三層迴圈 \(l, i, k\)，每層最多 \(n\) 次 → \(O(n^3)\)。
  • 精確地數：長度 \(l\) 的區間有 \(n-l+1\) 個，每個試 \(l-1\) 個 \(k\)： $$\sum_{l=2}^{n}(n-l+1)(l-1)=\frac{n^3-n}{6}=\Theta(n^3).$$
  • 直觀：\(\Theta(n^2)\) 個子問題 × 每個 \(O(n)\) 個選擇。
  • 空間 \(\Theta(n^2)\)（m 和 s 兩張表）。

Top-down：memoization

只要對 RECURSIVE-MATRIX-CHAIN 做小改動，就能得到 \(O(n^3)\) 的 memoized 版本：

n = p.length - 1
for i = 1 to n
    for j = i to n
        m[i, j] = ∞          // ∞ = 還沒算
return LOOKUP-CHAIN(m, p, 1, n)

if m[i, j] < ∞               // 算過了
    return m[i, j]
if i == j
    m[i, j] = 0
else for k = i to j - 1
    q = LC(m,p,i,k) + LC(m,p,k+1,j) + p[i-1]·p[k]·p[j]
    if q < m[i, j]
        m[i, j] = q
return m[i, j]
  • 為什麼是 \(O(n^3)\)：每個 \(m[i,j]\) 只會在第一次被呼叫時真的計算（之後都在第 1–2 行就回傳）。\(\Theta(n^2)\) 個表格項目，每個計算時跑 \(O(n)\) 圈迴圈 → \(O(n^3)\)。查表的呼叫也是 \(O(n^3)\) 次，每次 \(O(1)\)。
  • 在上面的遞迴樹打勾「用 memoization」可以看到樹被剪成多小。

Memoization vs. bottom-up

Top-down + memoBottom-up
寫法照遞迴式寫，加上查表 / 存表自己決定填表順序（依賴的格子先填）
會算哪些子問題只算真的需要的全部都算
常數有遞迴呼叫的額外開銷迴圈，常數通常較小
漸近時間通常相同（本題都是 \(\Theta(n^3)\)）
